# 美术圣经 V0.1（骨架）

> 来源：`总纲-项目规划书V1.md` §5.1 / §5.3 / §5.4 ｜ 状态：骨架版——**签收后才允许资产生产**
> 解决缺口 B5：原 Bible 除"鲜艳卡通风"外无任何视觉规范；现 `ToonMaterial.ts` 文件头自注 "final rendering direction has NOT been decided"。

## 1. 色彩系统

- 主色 5 + 元素色 4（火橙 / 冰蓝 / 雷黄 / 暗影紫，含色盲替代色相）+ 状态色 3
- 每个颜色给 HEX 与用途（待签收时填定）
- 方向：精致、鲜艳、卡通化的 3D 魔法奇幻风格

## 2. 材质与光照

- toon 三档 band 定案（现 `ToonMaterial.ts` 的 0.08 / 0.44 / 0.78 为**临时值**）
- 单主光方向 + 环境光值
- 禁用项：无写实 PBR、无法线细节

## 3. 形体与剪影

- 玩家 / 普通怪 / 精英 / Boss 体型比
- 头顶高度与镜头距离关系，保证俯视角轮廓可辨
- 相机锁定俯视角（见 §5 触控布局）

## 4. 可读性规则

- **元素用色相 + 状态用形状/图标**的双通道规则
- 预警形状与碰撞判定一致（Boss 地面预警红线）
- 特效层叠时的降级顺序

## 5. 触控布局（移动端）

横屏：左下虚拟摇杆（移动）；右下按钮簇 **5 键**：攻击（自动施放为主）/ **武器切换（新增）** / 技能Q / 技能E / Dash。所有按钮 ≥ 12mm 触控热区、半透明、拇指弧线排布。CameraRig **锁定俯视角**（移除玩家转视角自由度，保留微量偏移）。

## 6. 移动端性能红线（写进验收）

1. 中端手机横屏，同屏 60 怪 + 全特效：**P95 帧时间 ≤ 33.3ms（30FPS）且不触发热节流**
2. 同屏硬上限：普通怪 ≤ 60、精英 ≤ 2、投射物 ≤ 40、粒子系统 ≤ 12，超限延迟生成而非降帧
3. 首屏可交互 ≤ 5s（4G）、运行内存 ≤ 400MB、首包 ≤ 25MB；低配档自动降级（关 GPU 粒子/阴影/半分辨率）

## 7. 资产规格与量级

- 单资产预算（面数/贴图/材质数）、GLTF 格式、命名前缀规范（`env_forest_tree_a.glb` / `fx_fire_burn_loop`）
- 总量级：约 **60–80 模型、180 贴图、9 套粒子、45+ SFX、4 BGM**
- 许可证调研见 `美术-资产许可证调研.md`
