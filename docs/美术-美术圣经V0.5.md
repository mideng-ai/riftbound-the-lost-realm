### 3.3 Boss 三阶段形态变化要点（The Warden's Wake / Corrupted Bloom / Rift Unbound）

- **P1 守望者的低语**：半跪守望姿态，树皮完整，仅胸口一道细裂缝透紫光，单臂攻击。读法：威胁低、可贴身。
- **P2 腐化盛放**：起身，肩背绽出 3-5 朵发光腐化花苞，双臂藤蔓化延长 1.5 倍，攻击范围明显扩大。读法：范围威胁，"花"即危险区锚点。
- **P3 裂隙临界**：树皮成片剥落悬浮，露出体内裂隙能量核心（高亮紫），悬浮离地 0.4 比例，头顶枝冠折断张开成裂隙光环。读法：全阶段最高威胁，进入最终窗口演出。

### 4.2 特效层叠降级顺序（触发移动端预算红线时按序执行）

1. 关装饰性余烬/飘尘/死亡碎屑粒子 → 2. 命中粒子数量减半 → 3. 关拖尾 trails → 4. 降预警填充透明度（保留描边）。**不可降级项**：预警标记、受击闪白、死亡消散、Boss 核心发光。

### 4.3 地面标记与判定一致原则（红线）

预警贴花几何 = 碰撞判定几何，同尺寸、同角度、同圆心；禁止"标记比判定小"的欺骗。预警到命中的前摇时长全表统一由设计数值表给出，贴花仅做时间可视化（描边随前摇收拢）。

## §5 触控布局（移动端，与 V0.1 一致）

横屏：左下虚拟摇杆（移动）；右下按钮簇 **5 键**：攻击（自动施放为主）/ **武器切换** / 技能Q / 技能E / Dash。所有按钮 ≥ 12mm 触控热区、半透明、拇指弧线排布。CameraRig **锁定俯视角**（移除玩家转视角自由度，保留微量偏移）。

## §6 移动端性能红线（写进验收，与 V0.1 一致）

1. 中端手机横屏，同屏 60 怪 + 全特效：**P95 帧时间 ≤ 33.3ms（30FPS）且不触发热节流**
2. 同屏硬上限：普通怪 ≤ 60、精英 ≤ 2、投射物 ≤ 40、粒子系统 ≤ 12，超限延迟生成而非降帧
3. 首屏可交互 ≤ 5s（4G）、运行内存 ≤ 400MB、首包 ≤ 25MB；低配档自动降级（关 GPU 粒子/阴影/半分辨率）

## §9 待负责人拍板的 3 个美术决策

1. **Boss 主色相**：裂隙紫为主（术语表紫=裂隙系，推荐）、腐化绿为主（呼应"森林之主"）、或紫绿双色渐变？影响 B01-B03、A07 与全部 Boss 特效。
2. **玩家袍装颜色**：焰橙渐变米白（呼应 Emberward 之名与火元素主视觉，推荐）vs 青蓝（与环境色区隔更强但弱化"归焰"主题）？
3. **精英/Boss 是否加体积光轮廓（volumetric rim glow）**：§2 定案 rim light 强度 0.35 已够识别；体积光更醒目但手机端有帧成本，需在 §6 红线实测后裁决（默认：不加，用 rim + blob 即可）。
