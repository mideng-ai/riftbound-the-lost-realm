## §1 结论摘要

**方案可行性：APPROVE。** 51（实为 48，见下）个音效 + 4 首 BGM + 2 层环境音全部可由 `OscillatorNode` / `AudioBufferSourceNode`（运行时生成噪声缓冲）/ `BiquadFilterNode` / `GainNode` 包络 / 频率自动化合成，不依赖任何外部音频文件，满足首包 ≤ 25MB 红线（音频资产体积 = 0 B）与 429 出图额度失败后的零资产约束。合成计算量：峰值 16 个 SFX 声部 + 6 个常驻 BGM/环境声部，在中端手机 Web Audio 线程可承受（不占 JS 主线程渲染预算）。

**总体结论：CONCERNS**，阻塞项只有一条：

## §2 合成配方总原则

### 2.1 统一参数记号（所有配方表通用）

| 记号 | 含义 | 取值与 Web Audio 对应 |
|---|---|---|
| `W` | 波形 / 声源 | `sin` / `tri` / `saw` / `sq` = `OscillatorNode.type`；`n:w` = 白噪声 `AudioBufferSourceNode`（运行时 `Math.random()` 生成 2 s 循环缓冲）；`n:p` = 粉噪声（Paul Kellet 近似，同一缓冲生成函数）；`PW:k` = `PeriodicWave` 仅前 k 次谐波 |
| `F0→F1(t)` | 基频起始→终点 Hz，`t` 秒内自动化 | 未标 `lin` 默认 `exponentialRampToValueAtTime`；`lin` 为 `linearRampToValueAtTime`；`/` 分隔多段 |
| `ADSR` | `A/D/S/R`，单位秒；`S` 为 0–1 比例电平 | `GainNode.gain`：`setValueAtTime(0)` → `linearRampToValueAtTime(LVL,A)` → `linearRampToValueAtTime(LVL×S,A+D)` → `setValueAtTime(LVL×S,A+D+hold)` → `linearRampToValueAtTime(0,A+D+hold+R)`；`hold = DUR−A−D−R` |
| `FLT` | 滤波器 | `LP/HP/BP <截止Hz> Q<q>` = `BiquadFilterNode(type, frequency, Q)`；箭头表示截止频率在 DUR 内扫频 |
| `DUR` | 单个声部总时长（秒） | 从触发到完全静音 |
| `LVL` | 该声部进入总线前的峰值目标电平（0–1） | 多声部配方取各声部 LVL 中的最大值作为该 SFX 的标称电平 |
| `MOD` | 附加处理 | `+osc(波形,频率,延迟s,失谐cent)` 叠加振荡器；`detune ±xc`；`vib <Hz>/±xc` 颤音；`trem <Hz>/<0–1>` 振幅颤音；`+n:w HP<Hz> <秒>` 噪声瞬态层；`delay <秒> fb<0–1>` 单次回声（不用 Convolver，省内存）；`pan <起>→<终>` = `StereoPannerNode` |

**参数完整性约定：** 配方表每行 9 列全部填值，无 `TBD` / 占位符；未使用 MOD 写 `—`。所有噪声均在运行时生成，缓冲只在 AudioContext 解锁后创建一次并复用（白/粉各 2 s，44.1 kHz 单声道 ≈ 352 KB RAM，计入运行内存而非首包）。

### 2.2 总线结构与总电平

| 总线 | 内容 | 默认 `GainNode.gain` | 说明 |
|---|---|---|---|
| `master` | 全部 | 0.90 | 后接 `DynamicsCompressorNode` 限制器：`threshold=-3 dB, knee=6 dB, ratio=12:1, attack=0.003 s, release=0.12 s`，防削波 |
| `bus.music` | BGM-1~4 | 0.50 | 音乐"可感不可压"，任何时候不得盖过预警音 |
| `bus.sfx` | §3 全部 48 个音效 | 0.80 | 战斗反馈主体 |
| `bus.ui` | `sfx_ui_*` / `sfx_upgrade_pick` / `sfx_purchase` | 0.60 | 2D 无定位 |
| `bus.ambient` | AMB-1 森林风声 / AMB-2 裂隙低鸣 | 0.18 | 常驻循环层 |

合成层最终输出峰值目标 ≤ −1 dBFS；因浏览器无法直接测 LUFS，采用"峰值代理口径"作为落地验收（P-3 拍板项）。

### 2.3 优先级与抢占口径（对齐冻结 config）

`src/config/audioEventMapConfig.ts:127-137` 定义四级优先级与 16 音源上限。合成层落地规则：

1. **档位映射**：`bossWarn=40` ← `sfx_boss_warn_1/2/3`、`sfx_boss_phase_2/3`（P-2 拍板项）；`bossAttack=30` ← `sfx_boss_attack_1..6`；`affix=20` ← 6 个 `sfx_affix_*`；`normal=10` ← 其余全部。
2. **16 声部池**：预分配 16 个 SFX voice slot；BGM 4 首 + 环境 2 层为常驻节点，**不占** 16 声部（否则探索期会长期占用 6/16）。
3. **抢占**：池满时新请求仅在 `新档位 > 最老声部档位` 时抢占；同档位先到先服务，不抢占。被抢占声部走 **30 ms 快速释音**（`linearRampToValueAtTime(0, now+0.03)`）后回收 slot，禁止硬停振荡器（防爆音 click）。
4. **合并**：同一 ID 在 80 ms 内的重复触发合并为一次；单一 ID 限流 6 次/秒（60 怪同屏时防止 `sfx_staff_hit` 吃满池）。
5. **受击例外**：`sfx_player_hurt` 虽属 normal 档，触发时对 `bus.sfx` 与 `bus.music` 施加 −3 dB / 200 ms 闪避（ducking），保证始终可听（对应美术圣经 §1.3 受击白闪的听觉对等物）。

## §4 BGM 分层合成规格

> 通用调度：一个 `AudioContext.currentTime` 对齐的 look-ahead 调度器（25 ms 间隔、100 ms 预排）驱动所有音符；所有音符用 §2.1 的 ADSR 包络，`OscillatorNode` 触发后 `stop(t+DUR)` 自动回收。BGM 声部走 `bus.music`，不占 16 SFX 池。
> 通用音色：Pad = `tri`+`sin` 双振荡 detune ±5c；Pluck = `saw` 短 ADSR + `LP`；Bell = `sin` + 高八度 `sin`；Perc = 噪声/正弦瞬态。**禁止**使用任何采样鼓组或外部音源。

### 4.1 曲目总览

| 曲目 | 场景/时段 | 调式/音阶 | BPM | 循环长度 | 拍号 |
|---|---|---|---|---|---|
| BGM-1 准备 | 局外准备界面 | A 自然小调（A B C D E F G） | 68 | 28.24 s（8 小节） | 4/4 |
| BGM-2 探索林 | 单局 0:00–7:30 | D 多利亚（D E F G A B C） | 92 | 41.74 s（16 小节） | 4/4 |
| BGM-3 高压 | 7:30–10:00 | D 多利亚 + 降 E 经过音（紧张化） | 124 | 15.48 s（8 小节） | 4/4 |
| BGM-4 Boss | 10:00 起 | D 小调 → E 小调 → G 小调（三阶段转调） | 132 | 14.55 s（8 小节） | 4/4 |
| AMB-1 森林风声 | 全程户外 | 无调式（噪声） | — | 8 s 噪声缓冲循环 | — |
| AMB-2 裂隙低鸣 | 裂隙区/ altar / Boss 战 | 无调式（低频 drone） | — | 6 s（与 48/72 Hz 拍频同步） | — |

### 4.2 BGM-1 准备（局外）

- **分层**：L1 = A2/E3 持续 Pad（LP 600，LVL 0.35）；L2 = A3-C4-E4 八分稀疏琶音（每小节 3 音，tri，LVL 0.22）；L3 = E5 铃音主题动机，每 2 小节一次（sin+高八度，delay 0.35 fb0.3，LVL 0.18）。
- **叠加规则**：L1 常驻；进入宝石页加 L2；停留 > 30 s 加 L3（回响主题动机，呼应音效表"BGM-1 回响主题动机"）。
- **淡入淡出**：进入准备界面 2 s 淡入；`run.started` 触发时 1 s 淡出并切 BGM-2。无鼓、无紧张层。

### 4.3 BGM-2 探索林（0:00–7:30）

- **分层**：L1 = D2+A2 drone Pad（LP 500，LVL 0.33）；L2 = D3-F3-A3-C4 八分脉冲琶音（tri，LVL 0.25）；L3 = D4-A4-C5 十六分稀疏拨弦（saw+LP 1800，LVL 0.18）；L4 = 轻 kick（sin 60→40 Hz，落在 1、3 拍，LVL 0.20）。
- **密度随时间加密**（对齐"热身→升压"）：0:00–2:30 仅 L1+L2；2:30 起 2 s 淡入 L3；5:00 起 2 s 淡入 L4；7:30 与 BGM-3 交叉淡入淡出 4 s。
- **预警叠加**：`sfx_boss_warn_1/2/3` 触发时，BGM-2/BGM-3 的 L2 临时让位 0.6 s（音量 −6 dB），为最高优先级预警音让出频谱空间（配合 §2.3 抢占）。

### 4.4 BGM-3 高压战斗（7:30–10:00）

- **分层**：L1 = D2 驱动贝斯（saw 八分，LP 300，LVL 0.38）；L2 = D4-F4-A4-C5 十六分急促琶音（sq，BP 2000，LVL 0.28）；L3 = 打击层（n:w hi-hat 八分 + sin kick 四拍，LVL 0.26）；L4 = 预警动机层（sin 880/932/987 脉冲，仅由 boss warn 事件触发，与 `sfx_boss_warn_1/2/3` 同音高、同脉冲数，LVL 0.20）。
- **转调/过渡**：7:30 从 BGM-2 交叉淡入 4 s；保留 D 多利亚但引入降 E（Eb）经过音制造紧张；10:00 与 BGM-4 交叉淡入 3 s。
- **规则**：节奏加快后（124 BPM）任何时刻不得掩盖 bossWarn 档音效；L4 与 SFX 同相叠加形成"音乐预警 + 事件警报"双通道识别（听觉冗余，对应美术预警形状双通道）。

### 4.5 BGM-4 Boss（10:00 起）与三阶段转调

- **基础**：D 小调，132 BPM，8 小节 14.55 s 循环。
- **三阶段各一层 + 转调**（转调规则与美术圣经 §3.3 三阶段形态一一对应）：

| 阶段 | 视觉锚点 | 调性（累计转调） | 新增层 | 音乐特征 |
|---|---|---|---|---|
| P1 守望者 | 半跪、树皮完整、胸口细紫裂缝 | D 小调（基准） | L1 贝斯 D1/D2（saw, LP 240）+ L2 Dm Pad（D3-F3-A3）+ 稀疏 kick | 低威胁、可贴身：音区低、密度稀、带宽窄 |
| P2 腐化盛放 | 起身、3–5 花苞、藤蔓 ×1.5 | **E 小调（+2 半音）** | L3 腐化琶音（Em + B→Bb 半音紧张）+ 加密 hi-hat | 范围威胁：中频绽放、横向铺开 |
| P3 裂隙临界 | 树皮剥落、裂隙核心、悬浮光环 | **G 小调（自 E 再 +3 半音，累计 +5）** | L4 裂隙合唱（detune saw 堆叠 + n:w swell, BP 1200）+ 双倍速 kick | 最高威胁：音区最高、全频、最密 |

- **转调落地**：旧调所有振荡器 `detune` 在 1.2 s（P2）/ 1.5 s（P3）内线性滑到新调音分；旧层 0.8 s 淡出、新层 0.8 s 淡入重叠，避免断拍。
- **与 `sfx_boss_phase_2/_3` 的对齐点**（关键）：阶段切换领域事件在 `t=0` 同时触发两件事——① 播放对应阶段切换 SFX（配方见 §3.3，内含 Dm→Em / Em→Gm 的旋律转调）；② BGM-4 启动层切换与调性滑音。**SFX 的转调音高 = BGM 滑音的目标调**，两者在 `t=0` 同起、在 `t=1.2 s / 1.5 s` 同落；SFX 峰值（ADSR 的 A 段结束点）精确对齐 BGM 新层第一个强拍（小节首拍），形成"音乐换挡 + 事件强调"的同步冲击。SFX 不被 duck（bossWarn 档，见 P-2）。

### 4.6 环境层 AMB-1 / AMB-2

| 层 | 声源 | 滤波/调制 | 电平 | 循环/淡入淡出 |
|---|---|---|---|---|
| AMB-1 森林风声 | n:p 粉噪声缓冲（2 s 源，6 s 交叉淡化循环） | LP 700 Q0.5；LFO 0.08 Hz 扫截止 ±250 Hz；LFO 0.05 Hz 振幅 ±0.2 | 0.12（bus.ambient） | 户外常驻；进/出区域 2 s 淡入淡出 |
| AMB-2 裂隙低鸣 | sin 48 + sin 72（五度）+ saw 36 | LP 180；trem 0.15 Hz/0.35；增益随时间从 0.05→0.18 升压 | 0.05–0.18 | 裂隙区/祭坛/Boss 战启用；Boss 战 +0.08；2 s 淡入淡出 |

**叠加规则**：环境层与任一 BGM 曲目独立并行，不参与 BGM 交叉淡入淡出；AMB-2 与 BGM-4 的 D1/D2 贝斯可能低频叠压，故 AMB-2 在 Boss 战时用 LP 180 锁死低通并让出 60–120 Hz 给贝斯（自动降 0.05）。

## §5 移动端解锁与混音策略

### 5.1 AudioContext 解锁（对齐音效表 §5 / BGM §2 的 D-OPEN：采用裸 Web Audio）

1. **懒创建**：不在页面加载时创建 `AudioContext`；首次 `pointerdown` / `keydown` / `touchend` 监听器中 `new AudioContext()` 并立即 `resume()`；创建后移除监听。
2. **iOS 兜底**：同一手势内播放一个运行时生成的 1 帧静音 `AudioBuffer`（全零，`AudioBufferSourceNode.start()`），兼容部分旧 WebKit 的首声锁。
3. **前后台**：`document.visibilitychange` → 隐藏时 `ctx.suspend()`（省电、停时钟），恢复可见时 `ctx.resume()`；不做自动播放。
4. **采样率**：使用 `ctx.sampleRate`，噪声缓冲按该采样率运行时生成，无硬编码 44.1 kHz 资产。

### 5.2 同屏 16 音源上限在合成层的落地

- 16 个 SFX voice slot 的对象池（每个 slot 持有可复用的 `GainNode` + `BiquadFilterNode`；振荡器/缓冲源每次新建并自动回收）。
- 池满策略、优先级抢占、30 ms 快速释音、80 ms 合并、6 次/秒限流：全部照 §2.3 执行。
- BGM 4 + 环境 2 为常驻节点，与 SFX 池物理隔离；BGM 声部自身上限 12（4 曲过渡期最多 2 曲 × 各 6 层），环境 2，合计 Web Audio 活动源峰值 ≤ 16 + 12 + 2 = 30，低于浏览器常见 64 通道限制。
- 双通道 redundancy：所有 bossWarn 档音在左右声道等电平（不 pan），保证单耳/单声道设备可听（无障碍 P-3 关联）。

### 5.3 无障碍与听觉冗余（对应美术圣经的可读性规则）

- 所有关键音（预警、受击、死亡、Boss 阶段）均有视觉对等物（美术预警形状、受击白闪、核心发光），音频不是唯一信息通道。
- 六个预警/攻击以**音高 + 节奏脉冲数 + 音色**三编码区分，不只靠音量（色盲/听损双友好）。
- 分总线音量控制（master / music / sfx / ui / ambient）由设置界面暴露；"突然大音量"可关（对应 §2.2 的 −3 dB 限制器与 bossWarn 档上限）。
