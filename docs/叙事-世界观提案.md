# D-208_WORLD_LORE_PROPOSAL — 世界观与角色定位提案

> 版本：v0.1

## 1. 基调约束
- 鲜艳、明快、卡通化的 3D 魔法奇幻风格。
- 紧张感主要来自搜刮风险、敌人威胁和撤离选择，不采用压抑黑暗的整体美术基调。
- 不制作长篇剧情对话、过场动画或复杂任务线。

## 2. 推荐世界观简案
失落领域曾是魔法文明繁盛的地区。某次未知的裂隙事件后，区域与外界隔离，魔法生态和遗迹发生变化。玩家扮演一名受托进入失落领域的探索者，寻找遗物、装备和可带回的资源，再通过撤离点返回营地。

以上背景仅作为简案提案，不定义灾变真相、历史年表或复杂阵营。

## 3. 玩家身份与营地
- 玩家身份暂名「裂隙探索者」。
- 营地是远征准备与战利品整备的安全据点。
- 营地角色/商人只承担功能性服务，不需要复杂关系剧情。
- 玩家职业、姓名、阵营和完整背景暂不冻结。

## 4. 环境叙事
- 通过遗迹、破损装置、魔法植物、废弃营地和少量短文本表达世界信息。
- 每条环境文本控制在短句，避免打断战斗与探索。
- 首张地图森林主题仅为候选，不把 Shadowgrove 当作已确定正式名称。
