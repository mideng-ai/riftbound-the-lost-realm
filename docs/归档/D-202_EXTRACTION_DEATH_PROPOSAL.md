# D-202_EXTRACTION_DEATH_PROPOSAL — 撤离与死亡惩罚详细提案

> 版本：v0.1  
> 日期：2026-11-12  
> 状态：AI 推荐提案，等待项目负责人审查；不构成已确认规则  
> 项目：Riftbound: The Lost Realm

## 1. 设计目标

撤离系统必须服务于四大支柱中的「紧张刺激的撤离决策」：
- 玩家应持续知道自己已获得多少尚未保住的战利品。
- 玩家可以在风险可控时主动撤离，而不是只能等到计时结束。
- 深入高风险区域应有额外收益，但不能让撤离成为纯随机事件。
- 死亡必须有分量，但不能摧毁仓库资产或让玩家失去继续游戏的基础能力。

## 2. 推荐撤离流程

### 2.1 撤离点发现
**推荐提案：**
- 首张地图至少设置一个固定撤离点。
- 撤离点以清晰地标和地图/HUD标识提示；玩家进入一定探索进度或接近后，显示更明确的方向提示。
- 撤离点位置固定在地图骨架中，不因随机化而不可达。
- 是否设置第二个随机撤离点留作首版后续扩展，不作为最低实现。

### 2.2 启动与交互
**推荐提案：**
- 玩家进入撤离区域后，出现明确的「开始撤离」交互提示。
- 点击/按键启动约 6 秒的撤离读条（数值为测试起点，不是最终值）。
- 读条期间玩家仍处于战斗状态，敌人可以继续攻击。
- 玩家离开撤离区域、主动取消或死亡时，读条中断。
- 单纯受到伤害不自动取消读条，避免玩家因一次擦伤被系统强制判失败；但受击会造成生命损失，玩家仍需清理威胁或寻找安全窗口。
- 成功读条后立即结算撤离成功，并进入结果界面。

### 2.3 撤离点风险
**推荐提案：**
- 撤离点附近布置可读的地形和有限掩体，不设计无法理解的封闭陷阱。
- 撤离启动时可触发一次有限的敌人压力（例如附近敌人被吸引），但不建议无限刷怪。
- 撤离点风险来自玩家是否清理周边威胁、当前生命值和携带战利品价值，而不是突然生成无法反制的伤害。
- 是否启动敌人增援、增援数量和出现位置留待地图与原型测试。

## 3. 成功撤离后的资产处理

| 资产类别 | 推荐处理 |
|---|---|
| 本局拾取且成功带出的装备 | 进入仓库 |
| 本局拾取的普通资源 | 进入仓库/资源账户 |
| 本局未拾取或未成功带出的物品 | 不获得 |
| 已存入仓库的装备与资源 | 保留 |
| 已解锁的内容与永久进度 | 保留 |
| 本局临时状态/临时增益 | 清除 |

撤离成功应给出清晰的战利品清单，并区分「本局新获得」与「原有仓库资产」。

## 4. 死亡后的资产处理

**推荐提案：死亡丢失本局尚未成功撤离的全部战利品；仓库资产与基础出战能力保留。**

| 资产类别 | 推荐处理 |
|---|---|
| 本局拾取但尚未撤离的装备 | 丢失 |
| 本局拾取但尚未撤离的资源 | 丢失 |
| 已存入仓库的装备与资源 | 保留 |
| 永久解锁与长期进度 | 保留 |
| 本局临时状态/临时增益 | 清除 |
| 出战前选择的基础装备 | 建议保留，不因死亡销毁 |

说明：
- 不建议额外扣除仓库货币或永久成长等级。
- 不建议死亡后随机损坏或销毁基础出战装备；如未来需要耐久系统，应作为独立设计讨论。
- 死亡结算展示本局获得但失去的战利品、击杀数、探索进度与死亡原因（仅在能够可靠判断时展示）。

## 5. 边界案例

| 情况 | 推荐处理 |
|---|---|
| 玩家在撤离读条时离开区域 | 读条中断，不结算 |
| 玩家在撤离读条时死亡 | 立即死亡结算，未保住的战利品丢失 |
| 玩家在读条时受到伤害但未死亡 | 读条继续 |
| 玩家在读条时击杀最后一个附近敌人 | 读条继续，不重置 |
| 玩家背包已满 | 不允许拾取新物品；不影响已有战利品撤离 |
| 玩家已撤离后再次开始新局 | 上一局已保留资产不受新局死亡影响 |
| 玩家退出/刷新浏览器 | 本局恢复行为取决于 D-207 存档决策；D-202 不自行定义断线保护 |
| 撤离点被地形/随机物阻挡 | 地图生成规则必须保证撤离区域和路径始终可达 |
| Boss 未击败 | 不应阻止玩家撤离；Boss 为可选高风险目标，除非后续明确另行批准 |

## 6. 对 10–15 分钟战局节奏的影响

- 撤离点应较早可被发现，避免玩家到最后才知道出口位置。
- 10–15 分钟是目标战局时长，不是强制等待计时器。
- 玩家可以在获得满意战利品后提前撤离。
- 深入地图、挑战精英或 Boss 候选点应提升潜在收益与风险。
- Boss 不应成为每局强制条件；玩家可选择绕过高风险目标并带着已有收获撤离。
