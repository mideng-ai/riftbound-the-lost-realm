# D-206_CAMP_PROGRESSION_PROPOSAL — 营地与跨局成长提案

> 版本：v0.1  
> 日期：2026-11-12  
> 状态：AI 推荐提案，等待项目负责人审查；不构成已确认规则

## 1. 设计目标
营地是局内风险循环与跨局装备成长之间的连接点。它应让玩家快速整理装备、查看战利品、进行有限资源兑换，并在短时间内重新出发。

## 2. 推荐营地最小闭环
1. 撤离成功后，战利品进入仓库。
2. 玩家在仓库查看、装备或替换物品。
3. 玩家使用局外资源购买基础装备/有限补给，或解锁新的装备选择。
4. 玩家确认出战配置并开始下一局。

## 3. 推荐功能边界
- 仓库/整备：首版必须有；支持查看、装备、卸下和整理。
- 商人/兑换：推荐一个简单商店界面；不做复杂 NPC 关系。
- 解锁：优先解锁新的装备/效果选择，而非无限永久提高基础攻击力和生命值。
- 营地美术：首版可以是一个简洁场景或界面，不要求可自由装修。
- 单次整备流程应短，目标是让玩家快速回到下一局。

## 4. 资源经济建议
推荐首版先使用一种主要局外货币，避免多种材料造成早期经济负担。
- 局内拾取资源：成功撤离后转换/存入局外账户；死亡时按 D-202 最终规则处理。
- 局外货币：用于基础装备购买、有限补给或解锁新装备选项。
- 永久解锁：保留已解锁内容，不因单局死亡回退。
- 不建议首版引入多级材料、装备合成链、随机商店刷新或复杂升级树。

## 5. 成长原则
- 主要成长来自装备选择与新选项解锁。
- 永久数值加成应克制，避免玩家成长后旧敌人完全失去威胁。
- 玩家连续失败时仍能获得少量可理解的前进路径，但不建议把失败奖励做成无条件大量资源。
- 所有局外资产的保存与本地持久化方案遵循 D-207（阶段2处理）。
