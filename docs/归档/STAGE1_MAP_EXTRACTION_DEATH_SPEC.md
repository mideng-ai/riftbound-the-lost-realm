# STAGE1_MAP_EXTRACTION_DEATH_SPEC — 首图结构、撤离与死亡结算规格

> **版本：** v1.0  
> **日期：** 2026-11-12  
> **状态：** 已确认设计方向的关卡/流程规格；地图比例、密度与撤离数值须经原型验证  
> **适用范围：** 首版第一张地图、局内搜刮、撤离与死亡结算  
> **依据：** GAME_SCOPE.md v1.4、GAME_DESIGN_SPEC.md v2.1、STAGE1_CONFIRMED_DESIGN_BASELINE.md v1.0、DECISIONS_LOG.md v4.6  
> **决策：** D-202、D-203 已确认；不新增玩法决策。

## 1. 目标与范围

首图应让玩家在 10–15 分钟目标战局中形成可读的路线选择：安全探索、风险支线、深处高价值目标与主动撤离。地图空间认知必须稳定，随机变化用于重玩差异，而不是破坏路线可读性。

首版仅制作一张手工设计地图骨架，局内有限随机化敌人、资源、宝箱、事件与部分精英遭遇。撤离点固定在骨架中，始终可达。Boss 是可选高风险目标，不是撤离门槛。

## 2. 地图拓扑与区域功能

### 2.1 首图逻辑拓扑

~~~mermaid
flowchart TD
    A[入口与安全出生区] --> B[中央连接区]
    B --> C[石碑遗迹支线]
    B --> D[荆棘洼地支线]
    C --> E[深处裂隙高风险区]
    D --> E
    A --> F[固定撤离点]
    B --> F
    C --> F
    D --> F
    E --> F
~~~

此图表达区域连接关系，不表达最终地图比例、视野、道路宽度或具体坐标。地图设计必须保证从每个关键区域存在至少一条可行路线到撤离点。

### 2.2 区域规格

| 区域 | 主要功能 | 风险/奖励方向 | 最低要求 |
|---|---|---|---|
| A 入口/出生区 | 安全进入、熟悉控制、首批低压遭遇 | 低风险、基础资源 | 不被敌人出生点封锁；有清晰离开方向 |
| B 中央连接区 | 识别地标、路线分流、回撤判断 | 低至中风险 | 与入口、两条支线和撤离路线连接 |
| C 石碑遗迹 | 探索、宝箱、环境叙事 | 低至中风险 | 有可识别地标与可选奖励 |
| D 荆棘洼地 | 混合敌人、资源风险选择 | 中风险 | 提供不同于 C 的遭遇/地形体验 |
| E 深处裂隙 | 高风险高回报、精英或可选 Boss | 高风险 | 可绕过；不得封锁撤离 |
| F 固定撤离点 | 结束本局、保住战利品 | 可控压力 | 早期可发现、持续可达、可明确交互 |

区域名称为制作代号，正式专名可后续调整，不影响拓扑功能。

### 2.3 路线体验要求

- 出生区到中央区的路线应直观，玩家无需地图知识即可开始探索。
- 中央区至少提供两条有意义的路线选择；两条支线的风险/奖励或遭遇风格应存在可感知差异。
- 深处高风险区应是主动选择，不得以主线硬门、强制 Boss 或不可逆单向门迫使玩家进入。
- 撤离路线要能从各关键区域理解并抵达；撤离点不应被随机障碍、不可通行地形或敌人出生点封死。
- 关键地标应有视觉差异，不能仅靠颜色区分。
- 地图规模、道路长度、视野与移动速度共同决定实际探索耗时；不在本规格中虚构世界单位。

## 3. 有限随机化规格

### 3.1 允许随机化

- 普通敌人的种类、数量与初始位置（受区域风险预算约束）。
- 资源点与宝箱在预设候选锚点中的启用/内容选择。
- 少量环境事件的启用/关闭。
- 精英遭遇是否出现在指定高风险候选区。
- 战利品类别与稀有度（受区域风险与掉落规则约束）。

### 3.2 禁止随机化

- 出生点被阻断、出生即受到不可避免伤害。
- 固定撤离点被移除、移动或变为不可达。
- 出生区到中央区的基本连接断开。
- 关键地标全部缺失，或所有可选路线均无法辨识。
- 关键兴趣点、奖励或任务物件生成在不可达位置。
- 生成地形穿透、路线死循环、玩家卡死或不可恢复软锁。
- 每局强制生成 Boss 或以 Boss 击杀作为撤离条件。
- 随机化覆盖/堵塞撤离交互区。

### 3.3 生成流程与安全回退

1. 载入固定地图骨架与静态关键连接。
2. 从预定义候选锚点中抽取资源、宝箱、事件与遭遇。
3. 按区域风险预算验证敌人组合与奖励组合。
4. 执行出生区、关键兴趣点、撤离点的可达性检查。
5. 检查撤离交互区无阻挡，且至少一条安全回撤路径可通行。
6. 若任一关键检查失败，重新抽取随机内容；达到重试上限后回退到预先验证的安全配置。
7. 记录随机种子与失败原因，供复现问题使用。

具体生成算法与重试上限属于后续实现设计；阶段1只冻结安全不变量和验证证据要求。

## 4. 兴趣点与节奏密度

- 每局约 3–5 个兴趣点作为初始测试密度，不是最终硬数量。
- 兴趣点至少覆盖：低风险资源、路线/探索选择、高风险/高回报候选。
- 撤离点是独立导航目标，不计入兴趣点数量。
- 不要求每个兴趣点每局都启用；随机组合不得造成整局无奖励或风险分布失衡。
- 通过测试记录玩家从出生到首次兴趣点、兴趣点间移动、深处区域停留与回撤时间，调整密度。
- 目标战局时长 10–15 分钟是体验目标，不是强制倒计时；玩家可提前撤离。

## 5. 撤离交互流程

### 5.1 状态机

| 状态 | 进入条件 | 玩家/系统行为 | 退出条件 |
|---|---|---|---|
| Undiscovered | 尚未发现撤离点 | 不显示精确交互提示；可通过地标/地图逐步识别 | 玩家发现或接近撤离点 |
| Available | 撤离点已发现 | 显示方向/地标提示；玩家可前往 | 进入撤离交互区域 |
| InRange | 玩家处于撤离区域 | 显示「开始撤离」操作 | 主动启动→Channeling；离开→Available |
| Channeling | 玩家主动启动读条 | 读条推进；战斗仍继续；允许玩家继续承受伤害 | 读条完成→Extracted；离开/主动取消→InRange 或 Available；死亡→Dead |
| Extracted | 读条完成 | 锁定本局成功撤离结果，结算本局战利品 | 进入结果界面/营地 |
| Dead | 角色生命归零 | 立即终止撤离与战斗，按死亡规则结算 | 进入死亡结果界面 |

### 5.2 规则

- 撤离点固定、提前可发现且始终可达。
- 玩家进入交互区域后必须主动启动读条；靠近撤离点不会自动撤离。
- 读条期间玩家仍处于战斗状态，敌人可继续攻击。
- 离开交互区域、玩家主动取消或角色死亡时，读条中断。
- 单纯受到伤害但未死亡，不自动中断读条。
- 成功完成读条后立即锁定撤离成功，进入结算；不得因之后同帧到来的伤害或敌人攻击回滚成功结果。
- Boss 未击败不影响撤离资格。
- 撤离点是否触发有限增援不是已确认必需功能；若采用，必须有限、可读、可反制，不得无限刷怪。

### 5.3 测试起点

- 撤离读条约 6 秒。
- 撤离区域半径约 3.0 世界单位。
- 一个固定撤离点。
- 上述读条与半径均是测试起点，须结合角色尺寸、移动速度、受击频率与地图尺度验证。

## 6. 战利品、仓库与死亡结算

### 6.1 资产状态定义

| 状态 | 含义 | 可否在本局死亡后保留 |
|---|---|---|
| Run Loot | 本局拾取、尚未成功撤离的装备/资源 | 否 |
| Banked Assets | 之前成功撤离并进入仓库/账户的装备与资源 | 是 |
| Permanent Unlocks | 已完成的永久内容/装备选项解锁 | 是 |
| Base Loadout | 出战前已选择的基础出战能力/装备 | 是 |
| Temporary Run State | 本局临时增益、临时状态与遭遇状态 | 否 |

### 6.2 成功撤离

1. 锁定本局撤离成功状态。
2. 汇总本局已拾取且可带出的物品与资源。
3. 将其转入仓库/对应资源账户。
4. 清除本局临时状态。
5. 展示本局新获得内容、资源变化与关键战绩。
6. 返回营地/整备界面。

不得重复结算同一物品；结果界面重复打开、刷新或重复触发结算不能再次增加资产。具体持久化/幂等实现由 D-207 阶段2技术 Spike 决定。

### 6.3 死亡

1. 立即停止战斗输入、自动攻击和撤离读条。
2. 本局尚未成功撤离的 Run Loot 全部丢失。
3. Banked Assets、Permanent Unlocks、Base Loadout 保留。
4. 清除 Temporary Run State。
5. 展示本局失去的战利品、击杀数、探索进度；死亡原因只有在可可靠判定时才展示。
6. 返回结果界面/营地。

死亡不得额外扣除仓库货币、永久成长等级或销毁基础出战装备；首版不加入装备耐久/随机损坏。

### 6.4 背包满载边界

- 背包满时禁止新拾取，并给出明确原因反馈。
- 背包满不影响已携带战利品撤离。
- 不允许用静默覆盖旧物的方式处理新物品。
- 若后续加入替换拾取，必须显示将被替换物品并要求玩家确认；该替换交互不在当前最低规格内。

### 6.5 浏览器退出/刷新

本局中刷新、崩溃、断网后的恢复与结算不在 D-202 冻结范围内，必须等待 D-207 阶段2存档 Spike。首版不得在未验证前宣称支持断线续局或安全恢复。

## 7. 验收用例

| ID | 场景 | 预期 |
|---|---|---|
| MAP-01 | 新局生成首图 | 固定骨架、入口、中心、两支线、深处高风险区与撤离点均存在 |
| MAP-02 | 从出生区前往中央区 | 路线清晰且出生区无不可避免伤害 |
| MAP-03 | 从每个关键兴趣区前往撤离点 | 至少一条可通行路径 |
| MAP-04 | 随机化抽取障碍/遭遇 | 不堵塞出生点、关键连接与撤离区 |
| MAP-05 | 随机化导致可达性失败 | 系统重抽或回退安全配置，不生成软锁地图 |
| MAP-06 | 深处 Boss 未击败 | 玩家仍可离开并撤离 |
| MAP-07 | 不同随机种子重复生成 | 核心拓扑稳定，遭遇/资源/事件产生有限变化 |
| EX-01 | 进入撤离区但不按交互 | 不自动开始撤离 |
| EX-02 | 主动启动撤离读条 | 读条开始，战斗仍继续 |
| EX-03 | 读条期间离开区域 | 读条立即中断 |
| EX-04 | 读条期间主动取消 | 读条立即中断 |
| EX-05 | 读条期间受伤但未死亡 | 读条继续 |
| EX-06 | 读条期间死亡 | 读条中断，进入死亡结算 |
| EX-07 | 读条正常完成 | 锁定成功撤离并进入结算 |
| EX-08 | Boss 存活时完成撤离 | 撤离仍成功 |
| LOOT-01 | 成功撤离携带物品 | Run Loot 转入仓库/资源账户一次 |
| LOOT-02 | 死亡时有未撤离物品 | Run Loot 全部丢失 |
| LOOT-03 | 死亡时已有仓库资产/永久解锁/基础装备 | 全部保留 |
| LOOT-04 | 背包满时拾取新物品 | 拒绝拾取并显示反馈，不覆盖旧物 |
| LOOT-05 | 重复触发结算入口 | 同一局资产不重复入账（具体技术实现待 D-207） |

## 8. 原型验证与记录要求

每轮至少记录：
- 随机种子、出生点/撤离点坐标、关键区域可达性结果；
- 玩家到达首个兴趣点与撤离点所需时间；
- 兴趣点数量、路线选择、深处区域进入率；
- 撤离读条开始/中断/成功次数与原因；
- 玩家撤离时携带价值、死亡损失价值、背包满载次数；
- 读条时长与区域半径的不同组合对紧张感/公平性的影响。

首轮建议测试读条 4/6/8 秒与区域半径 2.5/3.0/3.5 世界单位的组合；这些仅为测试矩阵，不代表已选定最终参数。

## 9. 完成标准与边界

- 地图骨架和所有关键区域功能有可读草图/拓扑证据。
- 所有关键区域到撤离点可达；随机化安全不变量有可复现测试。
- 撤离/死亡状态机与资产矩阵没有相互矛盾的边界。
- 背包满载、Boss 未击败、受伤/离开/死亡打断读条等情况有验收用例。
- 具体地图比例、兴趣点密度、读条/区域参数保持测试状态。
- 本规格完成不等于 GAME_SCOPE 最终冻结、阶段1正式验收或阶段2授权。
