# D-203_MAP_LAYOUT_PROPOSAL — 首张地图结构与有限随机化提案

> 版本：v0.1  
> 日期：2026-11-12  
> 状态：AI 推荐提案，等待项目负责人审查；不构成已确认规则

## 1. 推荐方向

采用「手工设计地图骨架 + 局内有限随机化」。

原因：
- 搜打撤需要玩家建立空间认知，不能让撤离路径和重要地标不可预测。
- 10–15 分钟单局不适合大型迷宫。
- 手工骨架便于控制手机视野、路线长度、风险分布和新手引导。
- 随机化放在遭遇、资源和事件层，足以产生重玩变化，且开发成本可控。

## 2. 首张地图提案

暂名：Shadowgrove（森林主题裂隙），名称仍待确认。

推荐地图采用一个中心连接区、两条中段支线和一个深处高风险区域：

```
                 [C 石碑遗迹]
                /             \
[A 裂隙入口]—[B 中央林道]——[E 深处裂隙]
                \             /
                 [D 荆棘洼地]

[A/B/D/E] 至少存在一条明确可达的 [F 撤离点] 路线
```

区域职能：
- A 入口：出生点、低压力教学遭遇、基础资源。
- B 中央林道：路线分流与方向地标。
- C 石碑遗迹：探索/宝箱/环境叙事，低到中风险。
- D 荆棘洼地：混合敌人、较高风险与资源回报。
- E 深处裂隙：高风险兴趣点，可放置精英或可选 Boss 候选。
- F 撤离点：可提前识别，路径始终可达，不要求玩家击败 Boss。

地图图仅表达拓扑关系，不是最终美术地图或比例图。

## 3. 随机化边界

### 允许随机
- 普通敌人的种类、数量与初始巡逻位置。
- 资源点与宝箱在候选锚点中的选择。
- 少量环境事件的启用/关闭。
- 精英遭遇是否出现在高风险候选区域。
- 战利品内容与稀有度（受区域风险约束）。

### 禁止随机
- 出生点被封死或立即受到不可避免伤害。
- 撤离点及其可达路径被阻断。
- 关键地标全部缺失。
- 高价值奖励全部生成在不可达区域。
- 随机生成导致路线死循环、地形穿透或玩家卡死。
- 把 Boss 设为每局强制遭遇。

## 4. 兴趣点密度与节奏

推荐每局提供约 3–5 个可见或可发现的兴趣点：
- 至少一个低风险资源点。
- 至少一个路线选择或探索点。
- 至少一个高风险/高回报候选点。
- 撤离点作为独立导航目标。

这只是测试起点。实际数量须根据地图尺寸、移动速度、探索耗时和手机视野验证。

## 5. 路线与撤离保证

- 出生区到中心区至少有两条视觉上可理解的路径选择。
- 每个关键兴趣区都必须存在可行撤离路线。
- 撤离点不能被随机障碍或敌人出生点完全包围。
- 地图随机化后运行可达性检查；若失败，重新抽取布局或回退到安全配置。
- 撤离点可以有敌人压力，但不能以无限刷怪阻止玩家完成撤离。

## 6. 首版地图范围控制

首版先完成一张地图，重复游玩靠遭遇、资源和事件的有限随机化支撑。
不纳入：
- 全程序生成迷宫。
- 多层地牢/大型开放世界。
- 复杂机关谜题。
- 多张地图同时制作。
- 每局强制 Boss。
