## 1. 世界观目标与内容边界

世界观只需回答玩家理解核心循环所必需的问题：
- 玩家为什么进入危险区域？
- 为什么要寻找装备、遗物与资源？
- 为什么需要撤离回营地？
- 营地在跨局成长中承担什么作用？

首版采用轻量魔法奇幻背景，服务探索与撤离，不建立庞大年表、阵营政治或长篇剧情系统。

## 2. 世界观简案（当前内容基线）

### 2.1 核心背景

魔法文明曾在这片区域繁盛。一次原因未知的裂隙事件发生后，区域与外界隔离，环境、遗迹与魔法生态出现异常。玩家作为远征探索者进入区域，搜寻遗物、装备和资源，再通过撤离点返回安全营地。

当前不解释裂隙事件的最终真相，不设定完整历史年表，也不强制玩家承担复杂主线任务。

### 2.2 玩家身份

- 玩家在产品文案中暂以「探索者」称呼。
- 「裂隙探索者」可作为内部描述，不作为必须展示的正式职业/阵营名称。
- 不冻结玩家姓名、种族、职业背景、阵营关系或个人剧情。
- 角色身份应保持易代入，不用大段背景文字阻断首次游玩。

### 2.3 营地定位

营地是安全的远征准备与战利品整备据点：
- 查看仓库与已带回的资产；
- 整理/更换出战装备；
- 使用局外货币进行简单兑换；
- 查看并使用已解锁的装备/效果选项；
- 再次进入裂隙区域。

商人/服务角色只承担功能性职责。首版不要求 NPC 好感、支线剧情、关系网或复杂对话树。

### 2.4 首图主题与名称

- 首图暂以森林遗迹/裂隙区域作为视觉主题候选，与轻量世界观一致。
- Shadowgrove 仅为工作代号，不是正式地图名称。
- 正式名称可在美术与内容制作阶段统一，不影响首图拓扑、风险分区和撤离功能。
- 场景叙事物件可包括石碑、破损魔法装置、异常植物、废弃营地与远征痕迹；具体资产数量不在阶段1冻结。

## 3. 环境叙事规则

- 主要通过场景地标、物件摆放、视觉变化与少量短文本传递信息。
- 单条环境文本只表达一个信息点，避免长篇说明。
- 叙事线索不能遮挡战斗预警、拾取提示、撤离交互或关键 HUD。
- 不要求玩家阅读文本才能理解移动、攻击、拾取、撤离等核心规则。
- 不制作长篇剧情对话、过场动画或复杂任务线。
- 环境叙事不应暗示与已确认死亡/撤离资产规则相冲突的设定。

## 4. 首局引导结构

### 4.1 引导原则

- 采用「首局轻量引导布局 + 首次触发时的渐进情境提示」。
- 每次只显示一个短提示；同一时间不得堆叠多个引导弹窗。
- 玩家正处于危险战斗、受击或执行关键操作时，非紧急提示延后。
- 提示可跳过、关闭并重新查看。
- 已完成的基础提示不在每局重复打断；玩家可从帮助入口重看。
- 首局敌人压力可以略低，但移动、普攻、技能、伤害、撤离与死亡规则必须与正式规则一致。
- 引导不是强制教程关卡，不以长文本或连续弹窗锁住玩家。

### 4.2 触发流程

| 顺序 | 触发时机 | 必须传达的信息 | 完成/关闭条件 |
|---|---|---|---|
| 1. 移动 | 首次进入地图、玩家尚未移动 | 手机左摇杆 / PC WASD；移动由玩家控制 | 首次有效移动或玩家跳过 |
| 2. 自动普攻 | 首次出现可攻击敌人 | 普攻自动触发并自动选敌；无有效目标时停火 | 首次自动攻击发生或玩家跳过 |
| 3. 手动技能 | 首个技能可用且周围压力允许 | 手机技能按钮 / PC Q、E；点击/按键手动施放 | 首次成功施放或玩家跳过 |
| 4. Dash | 首次遇到明确危险预警，或首次 Dash 可用 | 手机 Dash 独立按钮 / PC Space；方向跟随移动输入，否则沿角色朝向 | 首次 Dash 或玩家跳过 |
| 5. 拾取/背包 | 首次出现可拾取战利品 | 如何拾取、物品进入本局背包、背包满时拒绝新物品 | 首次拾取或玩家跳过 |
| 6. 撤离 | 首次发现/接近撤离点 | 撤离点可主动使用；进入范围后启动读条；离开/取消/死亡中断 | 首次成功启动撤离或玩家跳过 |
| 7. 结算 | 首次成功撤离或首次死亡后 | 成功撤离带出本局战利品；死亡丢失未撤离战利品，仓库资产/永久解锁/基础出战能力保留 | 结果界面核心信息已呈现 |

技能与 Dash 的提示顺序可根据实际遭遇安全窗口调整，但不得遗漏任何核心规则。若首次局内没有自然出现某个触发条件，帮助入口仍应可查看该项。

### 4.3 提示内容规范

- 每条提示建议一到两句短句，先说明操作，再说明结果。
- 按键/触控提示必须由当前平台输入映射生成，不在手机显示 Q/E 或在 PC 显示虚拟按钮。
- 不仅依靠颜色传递成功/失败；配合文字、图标、形状或动画。
- 不用模糊表述，例如“按键闪避”；应明确手机 Dash 按钮或 PC Space。
- 死亡/撤离提示严格遵循 D-202 的资产矩阵，不能把未撤离战利品描述成永久拥有。
- 技能提示不暗示自动技能或模式切换是首版功能。

## 5. 跳过、关闭与重新查看

- 首局引导提供清晰的「跳过引导」入口。
- 单条非关键提示可关闭；关闭不应误触发底层移动、攻击或拾取。
- 帮助/设置入口提供核心操作说明：移动、自动普攻、两种手动技能、Dash、拾取/背包、撤离/死亡规则。
- 玩家跳过后仍可从帮助入口重新查看全部基础提示。
- 已完成提示的记录属于产品行为；具体持久化方式由 D-207 阶段2 Spike 决定。
- 在 D-207 技术方案确认前，不承诺刷新/重装浏览器后引导进度一定保留。

## 6. 首局压力与安全时机

- 首局敌人压力可略低，例如降低早期遭遇密度或延长首次安全观察窗口；不得改变敌人攻击规则、角色伤害规则或撤离/死亡规则。
- 首次移动、自动攻击、技能与 Dash 提示尽量安排在低压力时段。
- 玩家处于受击、被包围、低生命或正在撤离读条时，非紧急提示延后。
- 撤离/死亡结算提示必须在结果界面清晰显示，不依赖玩家主动打开帮助。
- 首局压力调节不应使玩家误以为后续正常局的规则完全不同。

## 7. 双端呈现

### 手机
- 提示放置在屏幕上方或不遮挡战斗信息的区域。
- 不覆盖左下摇杆、右侧两个技能按钮与 Dash 按钮。
- 避开系统安全区、刘海与浏览器控件。
- 触控目标尺寸与文本字号通过真实设备可读性/误触测试决定。

### PC
- 使用键位名称提示：WASD、Q、E、Space。
- 提示布局适配宽屏与窗口尺寸，不遮挡角色及危险预警。
- 鼠标仅用于 UI 操作，不展示普通攻击手动瞄准教学。

## 8. 验收用例

| ID | 场景 | 预期 |
|---|---|---|
| LORE-01 | 玩家首次进入营地 | 能通过场景/UI 理解营地是整备与再次出发据点 |
| LORE-02 | 玩家探索首图 | 通过环境地标/短文本获得轻量世界信息，无需阅读长剧情 |
| LORE-03 | 查看地图名称/玩家称呼 | 暂名不会被误标为必须冻结的正式专名 |
| TUT-01 | 首次进入地图 | 显示对应平台的移动提示 |
| TUT-02 | 首次出现有效敌人 | 提示自动普攻与自动选敌，无需手动攻击键 |
| TUT-03 | 首个技能可用 | 提示手动技能输入，且不暗示自动施法 |
| TUT-04 | 首次危险窗口 | Dash 提示不遮挡操作区与危险预警 |
| TUT-05 | 首次拾取 | 说明物品进入本局背包及背包满载反馈 |
| TUT-06 | 首次发现撤离点 | 说明主动启动读条及中断条件 |
| TUT-07 | 首次成功撤离/死亡 | 资产保留/丢失说明与 D-202 一致 |
| TUT-08 | 玩家跳过引导 | 可继续正常游玩，不被教程锁定 |
| TUT-09 | 玩家从帮助入口重看 | 可重看全部核心操作与结算规则 |
| TUT-10 | 玩家正在受击/危险战斗 | 非紧急提示延后，不遮挡预警/输入 |
| TUT-11 | 手机与 PC 分别运行 | 平台键位/控件提示正确，无输入映射错配 |
| TUT-12 | 关闭提示/弹窗 | 不触发底层游戏操作，无输入穿透 |

## 9. 内容制作交付清单

- 一页世界观简案（本文件第2节可直接作为首版基线）。
- 首图环境叙事主题与物件类别清单（不要求先确定全部美术资产）。
- 营地功能角色/服务点列表（仅功能职责，不写复杂人物关系）。
- 首局提示触发表（第4节）与双端文案清单。
- 帮助入口核心规则说明。
- 手机/PC 首局可用性测试脚本与观察记录表。

## 10. 完成标准与边界

- 世界观背景、玩家称呼边界、营地定位与叙事范围明确。
- 首局移动、自动普攻、技能、Dash、拾取、撤离与死亡提示有触发/关闭/重看规则。
- 双端提示按已确认输入映射生成，且不遮挡关键操作。
- 首局敌人压力只调整遭遇强度，不改变核心规则。
- 暂名、短文本数量与最终文案可在内容制作阶段优化。
- 本规格完成不等于首版范围冻结、阶段1正式验收或阶段2授权。
