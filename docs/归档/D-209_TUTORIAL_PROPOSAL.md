# D-209_TUTORIAL_PROPOSAL — 首局新手引导提案

> 版本：v0.1  
> 日期：2026-11-12  
> 状态：AI 推荐提案，等待项目负责人审查；不构成已确认规则

## 1. 设计目标
新玩家无需外部说明即可完成首局，并理解普通攻击、手动技能、搜刮、撤离与死亡风险。引导必须短、渐进、可跳过，不得长期打断战斗。

## 2. 推荐方案
采用「首局轻量引导布局 + 首次触发时的情境提示」：
- 首次进入地图：提示移动方式与当前目标。
- 首次遇敌：提示普通攻击自动触发与自动选敌规则。
- 首次获得技能机会/技能可用：提示技能按钮与冷却。
- 首次接近可拾取物：提示拾取方式与背包状态。
- 首次接近撤离点：提示撤离交互与成功保留战利品的意义。
- 首次死亡或撤离结算：解释本局损失/保留规则，具体文案必须依 D-202 最终规则生成。

## 3. 引导节奏
- 每次只出现一个短提示，不连续堆叠弹窗。
- 玩家正在躲避危险或受击时，非紧急提示延后。
- 重要提示允许重新查看；已完成提示不在每局重复。
- 设置明确的跳过/关闭入口。
- 首局敌人压力可略低，但不能改变正式游戏核心规则。
- 进阶内容在首次遇到相关情境时再解释，不在开局长文轰炸。

## 4. 双端呈现
- 手机：短句提示避开摇杆、技能按钮与系统安全区。
- PC：提示位置适配较宽屏幕，键位提示按 D-201 最终方案生成。
- 提示不得只依靠颜色表达，须配合图标/文字。

## 5. 验收建议
- 无外部说明的新玩家能完成移动、理解自动普攻、使用至少一个技能、拾取战利品并完成撤离。
- 测试者能解释为什么要撤离、死亡会失去什么。
- 引导过程中无明显操作遮挡或连续弹窗打断。
- 跳过引导后仍可通过帮助入口查看核心规则。
