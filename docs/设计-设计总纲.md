# Riftbound: The Lost Realm — Game Design Bible V1.0

> 状态：核心系统规则已获项目所有者审核通过；数值属于第一轮实现测试参数（PROVISIONAL）。
> 用途：作为策划、程序、美术、音频、QA 与 Codex 多 Agent 的统一设计依据。
> 参考：The Spell Brigade 的核心战斗节奏与成熟玩法结构。只参考玩法体验和系统组织，不复制其受保护的角色、怪物、地图、技能、美术、音频或代码。

## 1. 项目定位与不可更改边界

### 1.1 游戏定位

- 名称：Riftbound: The Lost Realm
- 类型：3D 俯视角奇幻动作 PvE 怪物潮生存 / Roguelite。
- 首发地图：失落森林（The Lost Forest），只做一张固定地图。
- 首发核心角色：一名可操作的奥术法师；不在 V1.0 引入多职业选择。
- 首发武器：远程魔法法杖、近战魔法剑，可快速切换。
- 第一版优先完成完整单人游戏循环；多人合作不属于当前开发范围。
- 玩法参考：《The Spell Brigade》。通用战斗、怪物潮、局内升级、法术强化与视觉反馈优先采用成熟参考框架；本项目独有设计集中在本文件第 5–9 节。

### 1.2 已确认的项目边界（CONFIRMED）

1. 只有一张失落森林地图，不轮换地图，不随机切换地图。
2. 玩家始终在同一张地图中战斗。
3. 怪物数量、生成频率、等级与战斗强度随本局时间推进而提升；基础怪物潮节奏参考 The Spell Brigade。
4. 不采用搜打撤玩法：没有固定撤离点、撤离倒计时、撤离结算或“必须带着战利品撤离”的规则。
5. 不采用按地图区域逐层解锁难度的机制。视觉上可以有林地、遗迹、腐化植被等环境变化，但这些区域不承担固定的难度递进职责。
6. 玩家使用魔法法杖与魔法剑并可切换。法杖以远程魔法箭为基础普通攻击；魔法剑普通攻击为扇形挥砍，攻击范围采用项目所有者已确认的 B 方案，攻击速度为标准挥砍速度。
7. 装备只保留武器与宝石，不增加护甲、头盔、胸甲、腿部、戒指、饰品等装备部位，不引入随机装备词条或装备套装。
8. V1.0 的五项独有系统为：双武器成长、宝石、资源经济、森林 Boss、精英怪与随机事件。范围外的新系统不得擅自加入。
9. 普通怪物潮、通用局内升级和基础战斗体验优先参考 The Spell Brigade 的成熟结构，不另造一套重复的基础系统。
10. 所有玩法数值均须可配置。本文列出的数值是测试起点，不是无需测试的最终平衡承诺。

### 1.3 单局核心循环

1. 玩家进入失落森林，携带已强化的法杖、魔法剑及各自镶嵌的宝石。
2. 怪物从地图外围与有效生成点进入战场；玩家移动、攻击、切换武器并躲避攻击。
3. 击杀怪物获得局内经验；经验光点掉落在地面，玩家靠近后自动吸收。
4. 达到升级条件后，使用参考游戏风格的局内选择成长，强化武器攻击或技能构筑。
5. 怪物潮随时间增加数量、等级、种类和威胁；期间可能出现精英怪与随机事件。
6. 玩家收集金币、森林材料、元素碎片与宝石。
7. 约第 18 分钟腐化森林之主登场，玩家完成三阶段 Boss 战。
8. Boss 被击败则本局胜利；玩家生命归零则本局失败。
9. 结算时保存已拾取的永久资源、宝石与本局记录；返回局外成长，再开始下一局。

目标单局时长暂定 20–24 分钟：Boss 预警约 16:30，正式登场约 18:00，战斗目标约 2–4 分钟。

## 2. 参考游戏与原创边界

- 以 The Spell Brigade 作为核心玩法参考：俯视角怪物潮战斗、清晰的攻击反馈、局内成长选择、不断升级的敌人压力与易读的战斗节奏。
- 不要求逐项复制参考游戏的系统实现；优先复用成熟设计思路，再适配本项目的双武器和单地图目标。
- 本项目的原创重点是双武器永久成长、武器宝石镶嵌/合成、金币与材料经济、腐化森林之主、精英词缀和森林随机事件。
- 不复制参考游戏的具体美术资源、角色、怪物、法术、地图、音频、文本或代码。

## 3. 地图与时间驱动怪物潮

### 3.1 地图规则（CONFIRMED）

- 只有一张连续、固定的失落森林地图。
- 地图不轮换，不按局切换；V1.0 不做第二张地图。
- 不设置区域难度等级、区域解锁门槛或“越深入固定越强”的难度公式。
- 地图可有树木、遗迹、空地、障碍和地标；这些仅用于空间布局、视觉变化、战斗路线与事件摆放。
- 怪物可从地图四周或经校验的有效生成点持续进入战场。
- 生成点必须避开玩家近距离和不可到达位置；大型敌人与 Boss 必须有预警。

### 3.2 时间驱动 Spawn Director

Spawn Director 依据本局已进行时间控制：
- 每秒 / 每波生成预算；
- 普通怪、远程怪、元素怪和强化怪的生成权重；
- 怪物等级与属性缩放；
- 同屏怪物上限；
- 精英怪可用时间与数量上限；
- 当前战场压力、Boss 预警和 Boss 战状态。

时间推进的结果必须同时体现在“越来越多”和“越来越强”：
- 生成频率及每波数量逐渐增加；
- 同屏怪物数量上限按阶段提高，但受性能上限保护；
- 怪物等级与生命、伤害等能力逐步增长；
- 更高威胁的怪物种类逐渐进入生成池；
- 精英怪在中后期加入。

### 3.3 时间阶段（PROVISIONAL）

| 时间 | 怪物压力目标 | 内容方向 |
|---|---|---|
| 0–3 分钟 | 低 | 基础怪物、熟悉操作和建立首轮构筑 |
| 3–6 分钟 | 逐步提高 | 提高生成频率和每波数量 |
| 6–9 分钟 | 中 | 增加怪物类型，允许普通精英出现 |
| 9–12 分钟 | 中高 | 提高等级，加入强化怪物 |
| 12–15 分钟 | 高 | 精英领主可加入生成池，怪物潮更密集 |
| 15–18 分钟 | 很高 | 高等级怪物和精英压力；为 Boss 做预警铺垫 |
| 18 分钟后 | Boss 战压力 | 按 Boss 战斗状态协调普通怪生成 |

具体生成数量、等级、倍率和同屏上限必须通过可玩测试确定。不能把参考游戏的具体数值或未经验证的估计写成已知事实。

### 3.4 公平性与性能规则

- 禁止在玩家身边或屏幕中心无预警生成敌人。
- 生成预算须考虑当前存活怪物、玩家生命状态和最近受击压力。
- 同时攻击玩家的怪物数量需要受控；不能制造没有可躲避空间的攻击组合。
- 超出同屏上限时延迟生成，不允许无限堆积实体。
- 大型敌人、精英领主和 Boss 必须提供清晰登场提示。
- 随机系统必须支持 seed，便于复现平衡问题。

## 4. 武器系统

### 4.1 武器定义（CONFIRMED）

| 武器 | 定位 | 普通攻击 | 已确认要点 |
|---|---|---|---|
| 魔法法杖 | 远程输出 | 奥术魔法箭 | 优先发展远程攻击 |
| 魔法剑 | 近战范围输出 | 扇形挥砍 | 范围 B 方案、标准挥砍速度 |

两把武器从开局即拥有，可快速切换。各自独立保存强化等级和三个宝石槽位。

### 4.2 永久强化等级（规则已通过，数值 PROVISIONAL）

每把武器最多强化到 Lv.5。强化在局外进行，死亡不丢失。强化消耗森林材料。

| 强化 | 法杖 | 魔法剑 |
|---|---|---|
| Lv.1 | 基础攻击 | 基础攻击 |
| Lv.2 | 基础伤害 +8% | 基础伤害 +8% |
| Lv.3 | 基础伤害 +16%，弹道速度 +8% | 基础伤害 +16%，攻击恢复时间缩短 5% |
| Lv.4 | 基础伤害 +24% | 基础伤害 +24% |
| Lv.5 | 基础伤害 +32%，弹道速度 +12% | 基础伤害 +32%，攻击恢复时间缩短 10% |

魔法剑始终保持已确认的扇形普通攻击形状与范围方案。强化不得把普通攻击改造成另一种基础攻击。

### 4.3 强化消耗（PROVISIONAL）

| 升级 | 森林材料 |
|---|---:|
| Lv.1 → Lv.2 | 10 |
| Lv.2 → Lv.3 | 20 |
| Lv.3 → Lv.4 | 35 |
| Lv.4 → Lv.5 | 55 |
| 单把武器升满 | 120 |

两把武器全部升满共需 240 个森林材料。武器升级不消耗宝石。

### 4.4 边界

- 武器基础强化只调整武器基础性能。
- 局内法术/技能强化与进化沿用参考游戏风格的局内成长结构，避免与永久武器强化重复。
- V1.0 不制作随机武器词条、武器掉落等级或第三把武器。

## 5. 宝石系统

### 5.1 七种基础宝石（CONFIRMED）

| 宝石 | 类型 | 方向 |
|---|---|---|
| 火焰 | 元素 | 燃烧与持续伤害 |
| 冰霜 | 元素 | 减速与控制 |
| 雷电 | 元素 | 连锁电击 |
| 暗影 | 元素 | 暗影伤害与生命吸取 |
| 力量 | 属性 | 增加武器伤害 |
| 迅捷 | 属性 | 增加武器攻击速度 |
| 生命 | 属性 | 增加玩家最大生命 |

### 5.2 武器适配效果

| 宝石 | 法杖效果 | 魔法剑效果 |
|---|---|---|
| 火焰 | 火焰魔法箭命中后可燃烧 | 扇形挥砍命中后可燃烧 |
| 冰霜 | 魔法箭命中后可减速 | 剑击命中后可减速 |
| 雷电 | 魔法箭命中后可连锁闪电 | 剑击命中后可释放连锁电弧 |
| 暗影 | 暗影魔法箭伤害并有机会吸血 | 暗影挥砍伤害并有机会吸血 |
| 力量 | 提高法杖伤害 | 提高魔法剑伤害 |
| 迅捷 | 提高法杖攻击速度 | 提高魔法剑攻击速度 |
| 生命 | 提高玩家最大生命 | 提高玩家最大生命 |

同一种元素宝石在不同武器上必须通过对应武器的命中事件触发，不能把效果只做成换色。

### 5.3 普通品质初始效果（PROVISIONAL）

| 宝石 | 初始效果 |
|---|---|
| 火焰 | 命中有 15% 概率燃烧 2 秒，额外伤害为本次武器伤害的 40% |
| 冰霜 | 命中有 15% 概率使目标减速 25%，持续 1.5 秒 |
| 雷电 | 命中有 12% 概率触发连锁，最多传递至 2 个其他敌人，每次造成武器伤害的 45% |
| 暗影 | 命中有 10% 概率造成额外 40% 暗影伤害，并恢复玩家最大生命的 1% |
| 力量 | 对应武器伤害 +6% |
| 迅捷 | 对应武器攻击速度 +5% |
| 生命 | 玩家最大生命 +8% |

### 5.4 品质（CONFIRMED）与效果倍率（PROVISIONAL）

品质顺序：普通、优秀、稀有、史诗、传说。

| 品质 | 效果倍率 |
|---|---:|
| 普通 | 1.00 |
| 优秀 | 1.25 |
| 稀有 | 1.55 |
| 史诗 | 1.95 |
| 传说 | 2.40 |

品质提升效果强度，不改变宝石类型。元素触发概率默认不随品质提高；品质倍率主要用于触发后的伤害或增益强度。控制时长、Boss 控制强度及属性加成需要有配置上限，QA 需验证不会被叠加到失衡。

### 5.5 槽位与重复镶嵌（CONFIRMED）

- 每把武器 3 个宝石槽位。
- 两把武器各自保存槽位内容。
- 允许同一种宝石重复镶嵌。
- 镶嵌、拆卸、更换和合成在局外准备界面完成。
- 一局开始后不能自由更换已镶嵌宝石。
- 宝石没有随机副属性或随机词条。

元素宝石重复镶嵌时，不提高触发概率；增加效果强度。测试公式：同种宝石 1 颗为 1.0 倍，2 颗为 1.5 倍，3 颗为 2.0 倍。属性宝石按各自加成叠加。最终加成上限属于可调平衡配置。

### 5.6 合成（CONFIRMED）

三颗相同种类、相同品质的宝石合成一颗同种类的高一级品质宝石：
普通 → 优秀 → 稀有 → 史诗 → 传说。

- 合成不随机、不失败、不改变种类。
- 传说品质不能继续合成。
- 正在镶嵌的宝石不可直接合成，必须先拆卸。
- 合成只在局外进行。

## 6. 资源经济与永久成长

### 6.1 资源分类（CONFIRMED）

| 资源 | 用途 |
|---|---|
| 金币 | 局外永久成长 |
| 森林材料 | 法杖和魔法剑永久强化 |
| 元素碎片 | 制作对应元素的基础宝石 |
| 森林核心 | Boss 专属进度与后续高级内容解锁 |

宝石是装备物品，不是货币。金币、森林材料与元素碎片属于日常资源；森林核心由 Boss 提供。

### 6.2 掉落表（PROVISIONAL）

| 怪物 | 金币 | 森林材料 | 元素碎片 | 宝石 |
|---|---:|---|---|---|
| 普通怪 | 1 | 8% 概率掉 1 个 | 无 | 1% 概率 |
| 元素怪 | 2 | 15% 概率掉 1 个 | 40% 概率掉对应元素碎片 | 5% 概率 |
| 强化怪 | 3–4 | 30% 概率掉 1–2 个 | 视怪物元素类型 | 8% 概率 |
| 精英怪 | 8–12 | 保底 2–3 个 | 可能掉落 | 30% 概率 |
| Boss | 80–120 | 保底 10–15 个 | 专属奖励 | 稀有宝石奖励 |

掉落概率、材料数量和金币数量都要通过每局平均击杀数、平均局长和资源通胀测试校准。

### 6.3 元素碎片制作宝石（PROVISIONAL）

每颗普通元素宝石消耗：对应元素碎片 8 个 + 森林材料 5 个。分别用于火焰、冰霜、雷电、暗影宝石。属性宝石不纳入该制作配方，主要通过掉落与奖励获得。

### 6.4 金币永久成长（规则已通过，数值 PROVISIONAL）

第一版三个成长方向，均为 Lv.0–Lv.10：

| 成长方向 | 每级效果 | 上限 |
|---|---|---:|
| 法杖熟练度 | 法杖基础伤害 +2% | Lv.10 |
| 魔法剑熟练度 | 魔法剑基础伤害 +2% | Lv.10 |
| 森林生存能力 | 玩家最大生命 +1% | Lv.10 |

下一等级成本公式：C(L) = 100 + 50 × (L − 1)，其中 L 是准备购买的下一级等级。例：Lv.0→1 为 100 金币，之后每级增加 50 金币，最高 Lv.10。

### 6.5 结算与死亡保留（CONFIRMED）

- 本局已拾取的金币、森林材料、元素碎片在胜利或失败结算后保留。
- 已获得的宝石进入永久库存。
- 地面未拾取的物品不计入结算。
- 本局经验仅用于本局成长，不转成永久经验。
- 玩家死亡不清空已拾取的永久资源。
- 中途主动退出按失败结算处理。
- 森林核心只由 Boss 胜利奖励；V1.0 先记录持有量和 Boss 击败进度，未来内容未实现前不创建虚构消耗商店。

## 7. Boss：腐化森林之主

### 7.1 基本设定

- 名称：The Corrupted Forest Warden（腐化森林之主）。
- 出现地点：同一张失落森林地图，不加载第二张地图。
- 正式登场时间：约 18:00。
- 预警开始：约 16:30。
- 测试生命值：6000。
- 目标 Boss 战时长：2–4 分钟。
- 三阶段、六种攻击。
- Boss 不免疫任何一种武器或元素。
- Boss 高伤害攻击必须有可识别预警和可躲避空间。

### 7.2 登场流程（PROVISIONAL）

| 时间 | 反馈 |
|---|---|
| 16:30 | 森林环境、环境音与怪物行为出现异变 |
| 17:00 | 显示 Boss 即将登场提示 |
| 17:30 | 根须活动、Boss 登场特效开始 |
| 18:00 | Boss 正式登场 |

Boss 预警后停止生成新的主要随机事件。普通怪生成量可根据 Boss 战状态降低或调整。

### 7.3 阶段

| 阶段 | Boss 生命值 | 内容 |
|---|---:|---|
| 第一阶段：森林守卫 | 100%–65% | 根须突刺、扇形横扫、地面震荡 |
| 第二阶段：腐化苏醒 | 65%–30% | 加入腐化藤蔓、森林召唤 |
| 第三阶段：核心暴走 | 30%–0% | 核心爆发，攻击节奏提高 |

### 7.4 六种攻击（伤害与时序均 PROVISIONAL）

1. 根须突刺：地面标出线形预警区域，约 0.9 秒后突刺；测试伤害 20。
2. 扇形横扫：Boss 抬起树枝并显示扇形预警，约 1 秒后横扫；测试伤害 25。
3. 地面震荡：Boss 重击地面，约 1.2 秒后产生环形冲击波；测试伤害 18。
4. 腐化藤蔓：多个地面区域预警约 1.5 秒后生成藤蔓；持续 4 秒；测试伤害每秒 6。
5. 森林召唤：召唤 3 只普通森林怪物；召唤物有上限，不允许无限生成。
6. 核心爆发：Boss 停止移动并蓄能，约 2 秒后释放范围攻击；测试伤害 30；结束后核心暴露约 2 秒作为输出窗口。

### 7.5 Boss 质量规则

- 预警形状、范围、持续时间与实际碰撞判定一致。
- 同一时间不能叠加出没有安全落点的攻击组合。
- 每次重型攻击后应有可利用的输出窗口。
- 第三阶段提高攻击压力，不单纯堆伤害。
- 法杖与魔法剑都能正常造成伤害。
- 召唤物数量和普通怪生成量受控。
- Boss 死亡进入胜利结算。

### 7.6 奖励

- 大量本局经验（只记录为本局奖励，不转为永久经验）。
- 大量金币。
- 森林材料。
- 稀有宝石奖励。
- 森林核心。

具体奖励数量与稀有度由数据配置，经过完整单局测试后校准。

## 8. 精英怪与随机事件

### 8.1 六种精英词缀（规则已通过，数值 PROVISIONAL）

| 词缀 | 效果 | 测试参数 |
|---|---|---|
| 狂暴 | 移动和攻击速度提高 | 移速 +25%，攻速 +20% |
| 分裂 | 死亡后分裂成小怪 | 分裂为 2 只低生命普通怪 |
| 吸血 | 命中玩家后恢复生命 | 恢复本次造成伤害的 2% |
| 护盾 | 额外护盾 | 护盾值为最大生命的 30% |
| 召唤 | 定期召唤普通怪 | 每 12 秒 1 只，最多 3 只 |
| 剧毒 | 留下毒区 | 持续 3 秒，每秒伤害 4 |

### 8.2 精英等级

- 普通精英：1 个词缀。
- 精英领主：2 个不同词缀。
- V1.0 不做三个词缀的超级精英。
- 同时最多 2 只精英，其中最多 1 只精英领主。
- 禁止组合：护盾 + 吸血；召唤 + 分裂；狂暴 + 吸血。
- 词缀组合表必须数据驱动，便于 QA 验证。

### 8.3 精英出现节奏（PROVISIONAL）

| 时间 | 生成规则 |
|---|---|
| 0–6 分钟 | 不生成精英 |
| 6–9 分钟 | 开始生成普通精英 |
| 9–12 分钟 | 普通精英频率逐步提高 |
| 12–15 分钟 | 精英领主可进入生成池 |
| 15–18 分钟 | 精英出现频率提高，但受同屏上限约束 |
| Boss 战 | 根据 Boss 压力限制普通精英生成 |

### 8.4 五种随机事件

**遗落宝箱**
- 在地图可到达位置出现，玩家靠近后约 1 秒开启。
- 奖励池：金币、森林材料、宝石、元素碎片。
- 不出现于地图边界外、障碍内部或不可到达位置。

**元素祭坛**
- 玩家在火焰、冰霜、雷电、暗影中选一种。
- 对应元素效果强度 +15%，持续 90 秒。
- 对应元素怪出现权重提高。
- 增益和风险都需在 UI 中明确告知玩家。

**怪物巢穴**
- 巢穴持续生成附近怪物，有独立生命值。
- 测试生命值 1000。
- 摧毁后奖励金币、森林材料、元素碎片，并有概率掉落宝石。
- 有超时消失规则，不永久占据地图。

**古老祭坛**
- 生命献祭：消耗当前生命值的 15%，获得攻击伤害 +20%，持续 90 秒。
- 金币献祭：消耗 50 金币，获得攻击速度 +15%，持续 90 秒。
- 由玩家主动选择；不得强制扣除资源。

**精英入侵**
- 触发时给出明确提示，生成一只拥有两个兼容词缀的特殊精英。
- 击败后获得金币、森林材料、元素碎片和一颗普通或更高品质宝石奖励。

### 8.5 事件生成（PROVISIONAL）

- 第一场主要事件约在 3–6 分钟出现。
- 后续按约 3 分钟间隔产生事件机会，并加入随机时间偏移。
- 同时最多存在 1 个主要事件。
- 同一种事件不得连续出现。
- 玩家可以不参加；事件超时后消失。
- Boss 预警开始后停止生成新的主要随机事件。
- 事件完成、失败和超时都必须正确结束状态并清理对象。

## 9. UI、存档与通用系统的复用边界

- 通用战斗 HUD、局内升级选择、暂停、设置、结算、输入和音频系统参考成熟游戏结构，不因此新增第二套重复规则系统。
- UI 读取领域系统状态；UI 不能作为资源、伤害或成长的唯一数据源。
- 宝石镶嵌、拆卸、合成和永久成长在局外准备/成长界面操作。
- 局内不开放宝石更换，减少战斗中整理负担。
- 存档至少需要保存武器等级、宝石库存、镶嵌配置、金币、材料、碎片、森林核心、永久成长等级和设置。
- 当前工程只有 MockSaveAdapter；真实存档适配器仍为 OPEN，不得擅自把 localStorage 或 IndexedDB 作为最终方案。

## 10. 状态标签与数值管理

使用以下状态：
- CONFIRMED：项目所有者确认的规则或方向。
- PROVISIONAL：可运行的首轮数值或临时实现，需测试。
- OPEN：仍需项目所有者决策。
- DEFERRED：明确延后。
- IMPLEMENTED：代码已实现，不代表通过 QA。
- QA_VERIFIED：独立 QA 按验收标准通过。

所有伤害、触发率、掉落率、成本、数量、时长、同屏上限和成长倍率集中在配置/数据表中，不散落硬编码。调整数值不应要求修改业务逻辑。

## 11. V1.0 不做清单

- 不做地图轮换或第二张地图。
- 不做区域深度驱动的固定难度解锁。
- 不做撤离点、撤离倒计时或搜打撤结算。
- 不做护甲、头盔、胸甲、腿甲、戒指、饰品等装备部位。
- 不做随机装备词条、套装、装备交易市场。
- 不做第三把武器。
- 不做多职业阵容。
- 不做多人合作或 PvP，除非项目所有者另行批准。
- 不做多个 Boss；V1.0 只做腐化森林之主。
- 不做复杂制作树；只实现本文件定义的材料和宝石配方。
- 不擅自增加新的核心系统。

## 12. V1.0 验收总目标

一名玩家能够进入唯一的失落森林地图，使用法杖和魔法剑战斗；怪物潮随时间变多、变强；经验自动吸收并支持局内成长；玩家可以遭遇精英怪和随机事件；金币、森林材料、元素碎片与宝石正确掉落和保存；两把武器可以永久强化与镶嵌宝石；约 18 分钟迎战腐化森林之主；玩家胜利或死亡后正确结算并能开始下一局。

该闭环通过独立 QA 后，才可将 V1.0 核心玩法标记为 QA_VERIFIED。
