# 第二部分 · 设计补齐包（堵住五个 BLOCKER）

## 2.1 伤害结算管线（补 Bible §4.5，解决 B1）

### 乘区结构（三层加法区，层间乘法）

```
单发伤害 = 武器基础伤害 × A × B × C

A = 1 + 武器强化% + 金币熟练%     （局外基础区，加法合并）
B = 1 + Σ 宝石属性%               （宝石区，取最强×重复倍率，异属性加法合并）
C = 1 + Σ 局内临时%               （升级卡/事件 buff，加法合并，总上限 +150%）

元素触发效果独立结算，不进乘区。
```

### 四个未定义点的裁决

| # | 问题 | 定案 | 理由 |
|---|---|---|---|
| 1 | 强化表 +8/16/24/32 是累进还是总值 | **表中数值即该级总值（百分比加成）**，奇数级线性插值 +4%/级 | 平加会使后期基础伤害占比失衡 |
| 2 | 武器强化 × 金币熟练 | **A 区内加算** | 同源局外成长，乘算会双指数膨胀 |
| 3 | 品质 × 重复镶嵌 | 属性宝石**「取最强 × 重复倍率」**：力量传说×3 = 6%×2.4×2.0 = **28.8%**（非逐颗求和的 43.2%） | 逐颗求和会让"单槽三连"成为唯一主导策略 |
| 4 | 乘区叠加顺序 | 见上方三层结构 | 每层内部加法、层间乘法，无隐藏乘区 |

### 完整算例（基准校验用）

法杖基础 8 × A(1 + 32%强化Lv5 + 25%金币Lv10 = **1.57**) × B(1 + 28.8% 力量传说×3) × C(攻击卡I 12% + 攻击卡II 18% + 古老祭坛 20% = **1.50**) = **24.27/发**；间隔 0.5s → **DPS 48.53**，落在 25–50 峰值带 ✅

> **修订记录（D-09，2026-11-14 玩法设计总监裁定）**：原文写作「20%强化Lv5 = 1.45 → 22.4/发 → DPS 44.8」，其中 20% 是笔误。依据 `设计-设计总纲.md` §4.2 强化主表（Lv5 = +32%）、§2.1 裁决 #1（奇数级 +4%/级插值）、`src/config/playerConfig.ts` 配置表，三处均写 32%，且 `8/16/24/32` 为公差 +8 的等差数列——若取 20% 则序列变为 `8,16,24,20` 出现负增长，与"线性插值"矛盾。**权威值 = 32%，单发 24.27，DPS 48.53。** 详见 `docs/设计-D09-D08-R01数值锚点仲裁书.md`。

### TTK 基准（三条验收红线）

1. 普通怪 TTK **1.5–2.5s**
2. 玩家 **8–12 次受击死亡**
3. Boss TTK **2–3 分钟**（10 分钟局口径）

### Boss 6000 生命校验

Boss 期玩家面板 DPS 峰 35–50，走位有效系数 0.7 → 有效 **24.5–35**；6000 ÷ 35 ≈ **171s ≈ 2.9 分钟** ✅ 保留 6000。

> **修订记录（Q-NEW-2，2026-11-14）**：原文写「35–50 × 0.7 → 有效 30–40」，算术有误（35×0.7 = 24.5，不是 30）。已按正确乘积改为 **24.5–35**。171s 结论不变（仍按带下沿 35 计算，属保守口径）。
>
> **注（D-09 连带）**：上一条算例锚点由 44.8 修正为 48.53 后，本段的 171s 不受影响——本段除的是 DPS 带下沿 35，与 §2.1 的装备满配校验值不同源。按新锚点复核：6000 ÷ (48.53 × 0.7) ≈ **176.6s ≈ 2.94 分钟**，仍在 2–3 分钟红线内。

**平衡校验**：压力指数 R(t) = 当期猎犬实际 HP ÷ 目标 DPS 带中值 = 1.25 → 1.18 → 1.16 → 1.12，全程落在 **0.6–1.4** 带内 ✅

**失败代价定案**（解决"失败无代价"矛盾，不改 Bible §6.5）：
- 已拾取资源死亡保留（维持 CONFIRMED）
- **地面未拾取资源随局结束消失**——这就是设计的风险：拾取 = 安全，未拾取 = 损失
- 局内升级进度清零 + 时间成本
- 紧张感来自时间轴压力 + 拾取时机决策，不依赖死亡惩罚
