# D-205_EQUIPMENT_BUILD_PROPOSAL — 装备与构筑提案

> 版本：v0.1  
> 日期：2026-11-12  
> 状态：AI 推荐提案，等待项目负责人审查；不构成已确认规则

## 1. 设计目标
装备必须服务「有意义的装备成长」：战利品要能改变下一局的选择与玩法，而不是只增加一个更大的攻击数字。系统必须易于手机端背包操作，并控制首版内容量。

## 2. 推荐最小装备结构
- 武器槽：法杖或魔法剑，决定基础普通攻击形态。
- 防具槽：提供生存/防御方向的明确效果。
- 饰品槽：提供一个改变战斗行为或资源循环的特殊效果。
- 背包：只存放本局获得、尚未撤离的战利品；成功撤离后进入仓库。

以上槽位数量为提案，若 UI 或内容成本过高，可先减少装备槽，但不得让构筑只剩数值堆叠。

## 3. 稀有度建议
推荐四档：普通、优秀、稀有、史诗。
- 稀有度主要表达效果强度/复杂度与掉落期待，不只靠颜色区分。
- 每档的图标/边框/文字标签同时区分，兼顾色觉差异。
- 不在阶段1虚构掉率；掉率须按区域风险和原型数据制定。

## 4. 物品效果规则
首版推荐固定效果或少量可控词条，不做庞大随机词缀池、套装、合成、重铸。
每件装备至少具备：
- 唯一 ID 与显示名称。
- 装备槽位。
- 稀有度。
- 简短效果描述。
- 效果类型与参数。
- 来源/掉落区域（用于平衡与追踪）。
- 是否已装备/是否在本局背包中。

效果优先改变行为，例如：
- 法杖弹体获得有限穿透或弹体分裂。
- 魔法剑挥砍范围或剑气行为改变。
- 防具改变受击/护盾表现。
- 饰品强化技能冷却、拾取收益或闪避反馈。

## 5. 两种最低构筑示例
- 远程法杖构筑：法杖 + 提升弹体/施法节奏的饰品 + 生存防具；鼓励保持距离与稳定选敌。
- 近战魔剑构筑：魔法剑 + 强化扇形挥砍/近身生存的装备；鼓励靠近、多目标命中与路线选择。
- 第三种构筑作为目标项：技能强化方向；不得为了凑数牺牲前两种的清晰度。

## 6. 拾取与背包建议
- 地面战利品有清晰稀有度提示与物品类别。
- 接近物品后显示简短拾取提示；触屏使用大尺寸交互区域。
- 背包已满时明确提示，不静默丢弃或覆盖物品。
- 拾取、装备、替换与丢弃均需二次确认或可撤销反馈，避免手机误触导致不可逆损失。
- 局内背包界面应短时、可快速关闭，不要求玩家在战斗中阅读长描述。
