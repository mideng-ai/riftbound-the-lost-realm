## 1. 双端输入与战斗（D-201）

| 行为 | 手机浏览器 | PC 浏览器 |
|---|---|---|
| 设备方向 | 横屏为首版目标 | 横屏/桌面窗口 |
| 移动 | 左下虚拟摇杆 | WASD |
| 普通攻击 | 自动触发、自动选敌；无有效目标停火 | 自动触发、自动选敌；无有效目标停火 |
| 技能1/2 | 右下两个独立按钮，点击施放 | Q / E |
| Dash | 独立按钮 | Space |
| 普通攻击方向 | 系统依据已确认的附近威胁优先 + 距离辅助规则判断 | 同手机 |
| 鼠标 | UI 操作；不承担普通攻击手动瞄准 | UI 操作；首版不依赖鼠标指定普攻目标 |

技能默认点击即施放。只有技能效果确实需要方向或落点时，才使用按住拖动瞄准。首版特殊技能仅手动施放；自动技能与模式 UI 延后到首个小版本完成后重新研究。

允许移动中持续普通攻击。一次攻击/挥砍/弹体开始后保持该次动作一致；动作结束后重新评估目标。选敌层级为即时威胁优先，其次合理距离内的精英/Boss/远程或支援单位，最后最近普通敌人；目标有效时尽量保持，无有效目标时停止攻击。

**仍需原型验证：** 触控尺寸与误触率、技能瞄准例外的可用性、选敌距离/目标保持/遮挡、攻击间隔与动作窗口。

## 2. 闪避与防御（D-204）

- 首版采用单一 Dash，不增加独立格挡、招架或复杂防御系统。
- 手机独立 Dash 按钮；PC Space。
- 方向优先沿当前移动输入；无移动输入时沿角色当前朝向。
- Dash 不穿墙；使用独立冷却，不消耗技能共用魔法资源。
- 是否穿过普通敌人碰撞体、起始极短无敌窗口是否存在，交由 M1 原型对比验证；不得在验证前写死。

## 3. 地图、撤离与死亡（D-202、D-203）

### 3.1 地图骨架

首版先制作一张手工设计地图骨架，局内对普通敌人种类/位置、资源点、宝箱、少量事件及部分精英遭遇进行有限随机化。骨架至少包含：
- 入口与安全出生区；
- 中心连接区；
- 两条中段支线；
- 深处高风险区；
- 至少一个固定、提前可发现且始终可达的撤离点。

关键地标清楚、关键兴趣区可达。随机化不得封死撤离路线或强制 Boss 遭遇。每局约 3–5 个兴趣点只是密度测试起点。

### 3.2 撤离流程

1. 玩家可在获得满意战利品后主动前往撤离点。
2. 进入撤离区域后，由玩家主动启动读条。
3. 离开区域、主动取消或死亡时中断读条。
4. 单纯受到伤害但未死亡，不自动中断。
5. 读条完成后成功撤离，本局可带出战利品进入仓库。

约 6 秒读条、约 3.0 世界单位区域半径仅为测试起点，不是冻结数值。

### 3.3 死亡资产边界

| 资产 | 死亡结果 |
|---|---|
| 本局尚未成功撤离的战利品 | 丢失 |
| 已进入仓库的资产 | 保留 |
| 永久解锁 | 保留 |
| 基础出战能力 | 保留 |

Boss 为可选高风险目标，不阻止玩家撤离。撤离点增援如采用，必须有限、可读、可反制，不得无限刷怪。

## 4. 装备与构筑（D-205）

- 三个候选装备槽位：武器、防具、饰品；若手机 UI 或内容成本过高，可在保留玩法行为差异的前提下缩减。
- 装备以固定效果或少量可控词条为主；首版不做庞大随机词缀池、套装、合成或重铸。
- 稀有度四档：普通、优秀、稀有、史诗；掉率后续平衡。
- 至少两种明显不同构筑：远程法杖与近战魔剑；第三种技能强化构筑为争取目标。
- 背包满时禁止新拾取并明确反馈；高风险不可逆操作需确认或可撤销。

## 5. 营地成长（D-206）

- 首版营地聚焦仓库/整备、简单兑换与少量装备选项解锁。
- 使用一种主要局外货币。
- 永久成长优先解锁新装备/效果选择，不依赖无限永久属性堆叠。
- 营地以轻量场景或界面呈现；不做自由装修、复杂 NPC 关系、多级材料链或庞大技能树。
- 撤离成功后战利品入仓库；资源兑换与永久解锁遵循上述死亡资产边界。

## 6. 世界观（D-208）

魔法文明曾繁盛，未知裂隙事件使区域与外界隔离。玩家作为探索者进入区域搜寻遗物、装备和资源，再撤离返回安全营地。营地承担远征整备据点功能；商人/服务角色只承担功能职责。以遗迹、环境物件和少量短文本表达世界信息，不做长篇对话、过场或复杂任务线。“裂隙探索者”和“Shadowgrove”均为暂名。

## 7. 新手引导（D-209）

- 首局采用轻量引导布局 + 首次触发时的渐进情境提示。
- 顺序覆盖移动、自动普攻、手动技能、拾取/背包、撤离与死亡结算。
- 每次只显示一个短提示；危险战斗期间延后非紧急提示。
- 允许跳过、关闭与重新查看。
- 首局敌人压力可略低，但不改变核心规则；手机提示避开操作区，PC 提示按键位基线呈现；死亡/撤离文案必须遵循已确认结算规则。
