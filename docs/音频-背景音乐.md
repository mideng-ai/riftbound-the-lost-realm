# 背景音乐（AUDIO_BGM_V1）

> 来源：`总纲-项目规划书V1.md` §5.2 ｜ 状态：曲目结构定案，资产待 S5 收口阶段落实

## 1. 曲目结构（4 首 + 环境层 2–3）

| 曲目 | 场景 | 要点 |
|---|---|---|
| BGM-1 准备 | 局外准备界面（宝石/强化/金币成长） | 平静、神秘，回响主题动机 |
| BGM-2 探索林 | 单局 0:00–7:30（热身→升压） | 舒缓渐入，随阶段分层加密度 |
| BGM-3 高压战斗 | 7:30–10:00（高压 + 预警） | 节奏加快，预警点叠警报动机 |
| BGM-4 Boss | 10:00 起 Boss 战 | 三阶段各一层，阶段切换时转调 |
| 环境层 | 森林风声/裂隙低鸣 | 与任一曲目叠加，按区域混合 |

## 2. 技术约束

- BGM 分层/交叉淡入淡出方案随音频引擎选型（Babylon AudioEngine vs 裸 Web Audio）一起定
- Boss 三阶段切换的音乐衔接须与 `sfx_boss_phase_2/_3` 对齐
- 移动端自动播放解锁策略与音效侧共用一套（见 `音频-音效事件表.md` §5）
- 资产格式与大小预算待定（建议 OGG，单曲 ≤ 4MB，计入首包 ≤ 25MB 红线）
