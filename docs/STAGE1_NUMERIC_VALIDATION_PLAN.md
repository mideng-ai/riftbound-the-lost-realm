> 版本：v0.1  
> 日期：2026-11-12

> 项目：Riftbound: The Lost Realm

## 1. 目的与边界

本文件把现有数值提案整理为可验证的测试计划，避免把聊天中的临时数字当成正式游戏规则。

- 本文件不授权开始阶段2或阶段3。
- D-201 至 D-206、D-208、D-209 的待确认规则仍由负责人拍板。
- D-207 存档与 D-210 性能预算按路线图留到阶段2。
- 所有测试结果必须记录设备、浏览器、构建版本、测试场景和实际结果；未测试的内容不得标记通过。

## 2. 单位与坐标约定提案

**推荐提案：** 采用统一的游戏世界单位（World Unit, wu），不将单位直接等同现实米制长度。

理由：角色比例、摄像机缩放和地图尺度仍需通过原型确定；抽象单位更容易整体调整。

建议约定：
- X/Z：地面平面坐标。
- Y：高度。
- 移动速度：wu/s。
- 距离/半径：wu。
- 角度：度。
- 时间：秒。
- 生命/伤害：HP。

角色、敌人、拾取物、攻击范围都必须使用同一套坐标与单位定义。实际碰撞体尺寸由模型/占位体比例确定后再冻结。

## 4. 测试顺序

### T-01：移动与镜头
观察：
- 角色能否在手机触控下平滑移动。
- 斜向移动是否归一化，避免速度异常。
- 摄像机是否能持续保持角色与附近兴趣点可读。
- 地形碰撞是否导致卡边、抖动或穿透。

记录：移动速度、转向响应、卡碰撞次数、玩家主观可控性。

### T-02：自动选敌
观察：
- 即时威胁是否优先于远处普通敌人。
- 同等级威胁下距离是否合理影响目标选择。
- 当前目标是否保持稳定，不频繁跳转。
- 无有效目标时是否停止攻击。
- 目标死亡/离开范围/出现更高威胁后是否正确切换。

记录：每次切换原因、错误目标次数、目标保持时长、无目标停火行为。

### T-03：法杖
从单发直线弹体开始，不加入穿透、追踪、爆炸或散射。
观察：
- 玩家能否理解弹体方向与目标关系。
- 弹体速度是否让命中反馈清晰。
- 移动中自动攻击是否影响移动操控。
- 单个普通敌人的击败时间是否合理。

### T-04：魔法剑
保持 120° 扇形。
观察：
- 视觉弧线与实际判定是否一致。
- 多目标命中是否清楚。
- 攻击起手/判定/恢复是否可读。
- 目标切换是否导致挥砍方向突变。
- 玩家是否必须承担合理的近身风险。

### T-05：敌人与伤害
先使用一种近战追击敌人。
观察：
- 敌人前摇是否清楚。
- 玩家能否通过移动或最终确认的防御动作避开攻击。
- 连续受击是否过于惩罚。
- 玩家是否理解伤害来源。

### T-06：撤离闭环
只有 D-202 获批准后执行。
观察：
- 玩家是否提前识别撤离点。
- 是否能理解启动/中断条件。
- 撤离交互是否有足够风险但不显得随机。
- 成功/死亡结算是否准确处理战利品。

## 5. 调参原则

每轮测试遵循：
1. 一次只调整一个参数组。
2. 先校准输入、移动、目标选择与命中判定。
3. 再调攻击节奏、生命与伤害。
4. 再调敌人数量、遭遇间隔与掉落价值。
5. 最后调撤离压力与整体单局节奏。

不得同时改变玩家伤害、敌人生命、敌人伤害和刷新数量，否则无法判断变化原因。
