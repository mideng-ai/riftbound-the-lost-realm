## 1. 经验与升级规则

- 经验曲线：升到 L+1 级所需 **XP(L) = 40 × L^1.35**
  - L1–10 逐级需求：40 / 102 / 176 / 260 / 312 / 449 / 553 / 662 / 777 / 896
- 升级选卡时**时间冻结**（含 Boss 预警计时）——写进 TASK-01 时钟契约
- 每级 **3 选 1**
- V1.0 不做：稀有度、重抽、进化/合成
