# 资源与许可证调研清单

> 文档版本：v0.2  
> 最近更新：2026-11-12  
> 所属阶段：阶段 0（项目准备）  
> 状态：调研中；本清单不代表资源已获准集成或已通过项目验收。

## 1. 调研目的与记录规则

本清单用于记录可供《Riftbound: The Lost Realm》评估的第三方资源、工具与开源素材，重点核实来源、许可证、商业使用条件、署名要求、再分发限制及与当前技术路线的适配情况。

记录为“候选”不等于批准使用。正式集成前仍需：
- 核对资源仓库中的当前许可证、NOTICE 和具体文件说明；
- 确认实际使用的文件均被相应许可证覆盖；
- 将必要的版权声明和许可证文本纳入项目；
- 在项目实际技术环境中完成兼容性与视觉风格测试；
- 由项目负责人决定是否采用。

本阶段仅做资料调查和清单记录，不下载资源、不安装依赖、不集成代码，也不改变已选定的技术路线。

## 2. 候选资源

### 2.1 PixelFX

| 项目 | 调研记录 |
|---|---|
| 名称 | PixelFX |
| 来源 | https://github.com/patch-gg/pixelfx |
| 类型 | 基于代码的 2D 像素风格特效库，不是 3D 模型资源包 |
| 内容规模 | 仓库 README 介绍包含 244 个像素风格特效，覆盖火焰、爆炸、水、冰、闪电、奥术、暗影、状态效果、拾取物和 UI 等类别 |
| 浏览器相关能力 | README 描述支持浏览器 Canvas，并列出 Phaser、PixiJS、Kaplay、three.js 等使用场景；也支持导出透明 PNG 精灵表及帧数据 |
| 许可证 | 仓库声明代码与特效采用 MIT License，允许商业用途；使用时须遵守 MIT 许可证的版权与许可声明保留要求 |
| 许可证例外 | `gallery/fonts` 中的 Patch Pixel 字体不受仓库 MIT 许可证覆盖，需单独查看该目录的 NOTICE 和字体许可条件；不得默认将该字体纳入 MIT 授权范围 |
| 第三方来源说明 | 仓库 NOTICE.md 说明部分代码/特效改编自 Hugo Duprez 的 MIT 项目，以及 Hollow Crown 的 MIT 项目；使用前应保留并核查相关声明 |
| 可能用途 | 可作为火球、爆炸、冰霜新星、闪电、魔法阵、拾取提示等 2D 特效或 UI 动效的候选参考 |
| 与项目风格的匹配 | 当前项目目标为精致、明亮的 3D 卡通奇幻风格。像素风特效与主视觉可能不一致，不建议未经测试就作为主要战斗特效风格 |
| 与当前技术路线的适配 | 当前项目选择 Babylon.js。PixelFX README 明确列出 Canvas 和 three.js 等场景，但未明确列出 Babylon.js；是否能通过 Canvas 纹理、平面或 UI 叠加方式适配，仍属于待验证事项 |
| 当前状态 | 候选资源；尚未进行 Babylon.js 集成测试、视觉风格测试或实际项目验收 |
| 风险/注意事项 | 项目较新；集成前需检查实际源代码、依赖和许可证文件。不要把其像素特效误认为 3D 模型、材质或完整粒子系统 |

**初步结论：** 可以保留为 2D 像素特效候选资源，尤其适合原型阶段进行效果参考；暂不确定为正式游戏特效方案，不改变 Babylon.js 技术路线。

**核查来源：**
- 项目 README：https://github.com/patch-gg/pixelfx
- 项目 NOTICE：https://github.com/patch-gg/pixelfx/blob/main/NOTICE.md
- 字体许可说明（需在实际采用字体前单独核查）：https://github.com/patch-gg/pixelfx/tree/main/gallery/fonts


### 2.2 Quaternius（3D 角色、怪物、场景与道具）

| 项目 | 调研记录 |
|---|---|
| 名称 | Quaternius |
| 来源 | https://quaternius.com |
| 类型 | 风格化低多边形 3D 游戏资源包，包含角色、怪物、武器、道具、建筑、自然环境等 |
| 已核实候选包 | [Ultimate RPG Pack](https://quaternius.com/packs/ultimaterpg.html)：页面列出 100+ RPG 模型，格式 FBX/OBJ/Blend，页面标示 CC0；[Ultimate Fantasy RTS](https://quaternius.com/packs/ultimatefantasyrts.html)：页面列出 128 个模型，格式 FBX/OBJ/glTF/Blend，页面标示 CC0，内容为建筑和自然资产 |
| 许可证 | 需要特别注意：官网现有 [Quaternius Asset License（QAL）v1.0](https://quaternius.com/license.html)，更新日期 2026-08-28。该许可允许免费用于商业游戏和其他作品、修改和分发成品，免署名；但禁止将资源本身（包括修改版）作为独立素材包或类似产品再销售/再分发 |
| 旧资源许可 | 部分旧资源包页面仍明确标示 CC0。必须按具体资源包页面、下载文件内许可证和取得日期逐项记录，不能将整个 Quaternius 目录一概写成 CC0，也不能把新 QAL 规则自动套用到已按旧许可取得的资源 |
| 可能用途 | RPG 角色、怪物占位模型、武器、宝箱、建筑、森林/自然场景组件 |
| 与项目风格的匹配 | 低多边形卡通风格与项目目标有一定契合度；但需检查模型比例、色彩、细节密度是否统一 |
| 技术适配 | 常见格式包括 glTF/FBX/OBJ/Blend；glTF 可作为后续 Babylon.js 导入评估候选。实际骨骼、动画、材质和模型面数仍需逐包核查 |
| 当前状态 | 优先候选资源来源；尚未下载或导入项目，也未完成模型质量与技术测试 |
| 风险/注意事项 | 下载时保存资源页面、许可版本、取得日期及压缩包内 LICENSE/NOTICE。不得把模型原文件或改版模型单独打包分发 |

**初步结论：** Quaternius 值得作为角色、怪物和环境资源的优先调研来源。旧包页面标示 CC0 的资源与受 QAL 管辖的新资源必须分别建档。

### 2.4 KayKit / Kay Lousberg（角色、森林与动画）

| 项目 | 调研记录 |
|---|---|
| 名称 | KayKit（Kay Lousberg） |
| 来源 | https://kaylousberg.com/game-assets |
| 类型 | 风格化低多边形 3D 游戏资产，包含角色、森林、道具、资源和角色动画 |
| 已核实候选包 | [Characters: Adventurers](https://www.kaylousberg.com/game-assets/characters-adventurers)：5 个基础角色（额外档位另有内容），角色已绑定骨骼并带动画，含武器/配件；[Forest Nature Pack](https://kaylousberg.com/game-assets/forest-nature-pack)：免费档页面描述含 100+ 树木、岩石、灌木和草等模型；[Character Animations](https://kaylousberg.com/game-assets/character-animations)：页面列出 133 个角色动画，包括移动、闪避、受击、死亡、近战和施法等 |
| 许可证 | 上述具体资源页面声明 CC0，可用于个人及商业项目，无需署名；应以实际下载包附带的许可证和对应资源页为准 |
| 可能用途 | 玩家角色占位、冒险者/敌方人形角色参考、森林树木与植被、移动/闪避/施法等动画参考 |
| 与项目风格的匹配 | 低多边形、色彩统一的卡通风格，与项目方向有较高的初步匹配度；仍需检查是否过于通用或与其他资源包风格不一致 |
| 技术适配 | 页面列出 FBX、glTF 等格式；动画页说明动画主要面向 KayKit 角色骨架，其他人形模型可能需要骨骼重定向（retargeting） |
| 当前状态 | 优先候选来源；尚未下载、导入或测试 |
| 风险/注意事项 | 不同档位的免费内容与付费额外内容数量不同；清单只记录已核实页面所述范围，不能把付费档内容当作免费资源 |

**初步结论：** KayKit 值得优先评估森林环境和人形角色动画。若角色与动画使用不同资源来源，需提前评估骨架兼容和重定向工作量。

### 2.5 Poly Pizza（单模型检索补充来源）

| 项目 | 调研记录 |
|---|---|
| 名称 | Poly Pizza |
| 来源 | https://poly.pizza |
| 类型 | 多作者低多边形 3D 模型检索/分享平台 |
| 许可证 | 按模型分别标注；平台示例中同时存在 CC0 与 CC-BY 等许可，不可将平台所有模型视为同一许可证 |
| 可能用途 | 补充寻找单个宝箱、武器、树木、岩石、装饰物等缺失道具 |
| 与项目风格的匹配 | 取决于单个模型作者和作品，风格一致性风险较高 |
| 当前状态 | 补充检索来源；尚未选定具体模型 |

**初步结论：** 适合补齐少量零散道具，不建议直接从多个作者混搭大量模型来构建主视觉。

### 2.6 Sketchfab（单模型与付费模型补充来源）

| 项目 | 调研记录 |
|---|---|
| 名称 | Sketchfab |
| 来源 | https://sketchfab.com |
| 类型 | 3D 模型展示、下载与交易平台 |
| 许可证 | 需按模型具体许可核对。平台的 Standard 与 Editorial 许可不同；Editorial 许可不能用于商业或宣传用途。部分可下载模型采用 Creative Commons，通常需要作者及来源署名 |
| 可能用途 | 寻找特定怪物、遗迹、魔法道具等单体模型；也可评估付费标准许可模型 |
| 与项目风格的匹配 | 模型质量和风格差异很大，需逐个筛选 |
| 当前状态 | 备用检索渠道；尚未选定或购买任何模型 |
| 风险/注意事项 | 购买/下载前必须检查 Standard/Editorial 或具体 CC 许可；不得把模型源文件作为独立素材重新分发。CC 署名义务应随最终游戏及相关展示方式妥善处理 |

**初步结论：** 适合补充寻找独特模型，但许可审核和署名管理成本高于统一资源包，优先级低于 Quaternius、Kenney 和 KayKit。
